# 无畏契约（VALORANT）武器数据汇总

> **数据来源**：
> [游戏资料-枪械数据页](https://val.qq.com/game-data.html?pageType=2) —— 页面由 JS 动态渲染，数据来自官方 GraphQL API `https://api.val.qq.com/go/agame/graphql/graphiQL`（`guns` / `gun(id)` 查询，含伤害、属性、皮肤等完整字段）。

共收录 **19** 把枪械（截至 2026-08-28，按官方 API 顺序编号）。每位武器的完整数据见 [guns/](guns/) 目录下的独立文件。

> 📌 说明：官方枪械数据不含近战武器；编号按官方 API 顺序。
