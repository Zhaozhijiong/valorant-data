# v11.07版本

> **日期**：2025-10-02 ｜ **类型**：小版本
> **公告时间**：2025-10-01 13:52:13

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 10月2日 8:00进行不停机版本更新，更新过程中大家可以在游戏内正常进行对局，个别网吧由于使用较老的网盘更新方案，可能存在更新版本时偶发掉线的问题，为您带来的不便我们深表抱歉。
本次v11.07版本更新内容如下：
英雄更新
● 零
 ○ 零的战术监控&ldquo;视觉错误&rdquo;特效已被移除。此效果在连续快速切入摄像头时表现得最为明显。经过这次调整，玩家在频繁查看摄像头时错失某些信息的可能性将大大降低。
● 幻棱
 ○ 提升了幻棱的时光修罗场的清晰度，让玩家在闪避时清晰了解到范围边缘的位置。
玩法系统更新
● 随着新英雄和新技能的推出，我们希望让玩家在使用类似技能时，获得的信息也能较为一致。因此，我们将推出两组调整。
 ○ 可以放置和重新激活的技能现将使用特点鲜明的青绿色显示，以提升清晰度。

 ■ 维斯

模式更新
● 新游戏模式 斗牛 - 10月3日上线
 ○ 创建自定义游戏房间并邀请几个好友，即可进入新游戏模式。更多信息将在冠军赛决赛周末期间公布!
错误修复
● 英雄
 ○ 修复了尚勃勒的金牌猎头后坐力在某些情况下会以更快速度恢复的问题。
 ○ 炼狱的天基光束地图图标现已移除，其范围效果也已关闭。之前，其效果会在逐渐消失时停留一段时间，但这个时间超出了其在地图上对玩家显示的时限。
 ○ 修复了雷兹的头发，避免其在英雄选择界面进行特定活动时发生抽动。
 ○ 修复了不死鸟的火冒三丈即使没有与亚海悬城的玻璃重叠，还是可以将其击碎的问题。
已知问题
● 通用
 ○ 上周我们推出了一个修复版本，想要解决绝大多数导致英雄消失的错误。我们正在制作全面修复补丁，目前可能还有少数问题存留在游戏中。如果你在游戏中仍遇到此问题，请联系客服，告诉我们!
● 我们发现，目前存在某些问题，导致玩家在英雄选择界面锁定英雄后，游戏可能发生崩溃。我们将在11.08版本中推出解决办法。与此同时，大家可以关闭自己系统BIOS中的AVX512指令，以此避免问题的发生。
感谢您对《无畏契约》的支持和帮助!
