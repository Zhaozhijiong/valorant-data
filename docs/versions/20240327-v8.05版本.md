# v8.05版本

> **日期**：2024-03-27 ｜ **类型**：小版本
> **公告时间**：2024-03-26 19:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 3月27日8:00 进行不停机版本更新，更新过程中各位玩家可以在游戏内进行正常体验，更新过程中可能会出现短暂匹配异常或服务波动等情况，为各位玩家带来的不便我们深表抱歉。
这个版本中，我们将发布一名全新英雄&mdash;&mdash;暮蝶!暮蝶来自不列颠群岛北部，是《无畏契约》阵容中最新加入的控场英雄。我们十分期盼着看到大家使用这名英雄，也十分期待大家向我们提供反馈，还请大家踊跃发言哦!
此外，我们还对语音指示图标进行了小幅调整，并修复了一些错误。欢迎来到8.05版本，希望大家多多利用暮蝶的永生能力，祝你们玩得开心!
本次v8.05版本更新内容如下：
英雄更新
● 暮蝶正式上线!
 ○ 技能：
 ■ 霞染(E)：装备战场地图。按【射击】选择烟雾的部署位置，按【辅助射击】以确认，在指定地点创造阻隔视线的云雾。暮蝶可以在被击败期间使用此技能。
 ■ 整蛊(Q)：装备一块不朽精华碎片。按【射击】将其掷出，短暂延迟后碎片爆炸，对范围内所有目标施加短时间的【腐坏】效果。
 ■ 虹吸(C)：立即从被暮蝶击败或造成伤害的敌人身上吸收生命能量，获得加速和临时生命值。
 ■ 化蝶(X/终极)：被击败后，【激活】此技能以复活。复活后，暮蝶必须在限定时间内完成击败或助攻，否则将会回到被击败状态。
 ○ 想了解更多有关暮蝶的资讯，你可以查看《暮蝶开发访谈丨怎样在被击败后也能助力团队胜利?》，直接从开发团队那里获取更多信息!
 ○ 你也可以点击这里，看看我们最新的英雄如何超越生命的界定。
社交系统更新
● 语音指示图标
 ○ 我们对英雄头顶显示的语音指示图标进行了更新。现在开始，玩家可以更清楚地分辨自己可以/不可以听到哪些队友的语音了!语音图标还会同时展示队友的&ldquo;静音&rdquo;或&ldquo;未连接语音&rdquo;状态，并会根据房间成员是否使用房间语音发言进行区分。队伍语音活动的图标将保持不变。
错误修复
● 英雄
 ○ 修复了在网络连接不稳定的情况下进行游戏时，壹决决斗通牒(X)的掩护墙无法出现的问题。
● 玩法系统
 ○ 游戏现已支持5.1、7.1等多扬声器环绕声格式。注意：立体声混音不受影响。
已知问题
● 靶场
 ○ 在靶场选择英雄时的&ldquo;选择&rdquo;按钮文本展示错误，但不影响正常功能使用，我们将在下一个版本中修复该问题。
 
感谢您对《无畏契约》的支持和帮助!
