# v9.07版本

> **日期**：2024-10-10 ｜ **类型**：小版本
> **公告时间**：2024-10-09 21:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 10月10日 8:00 进行不停机版本更新，更新过程中大家可以在游戏内正常进行对局，若有偶现的匹配不可用请稍作等待即可恢复，为您带来的不便我们深表抱歉。
本次v9.07版本更新内容如下：
英雄更新
● 更新了英雄技能的投掷物、墙体和范围效果，使其在穿透/穿过星礈宇宙分裂时的音频表现更加一致
● 零的战术监控等可布置技能无法再置于贤者即将竖起的玉城的上方空间。
玩家进程系统更新
● 基础训练活动里程碑3的目标已更改。
 ○ 更改前：
 ■ 练习：在靶场练习
 ■ 练习：完成射击测试
 ○ 更改后：
 ■ 战略：与队伍合作拆除5个爆能器
 ■ 战略：与队伍合作部署5个爆能器
 ○ 奖励和可获取的经验值保持不变
错误修复
英雄
● 霓虹
 ○ 修复了霓虹在使用向后滑行时，可以在站立状态下滑行的错误。
地图
● 幽邃地窟
 ○ 更新了墙体碰撞逻辑，以防止英雄进入A区顶部的出界区域。
 ○ 更新了重生点屏障，以防止零的赛博囚笼落在屏障顶部。
● 源工重镇
 ○ 维斯的弧光玫瑰的闪光效果不再能穿透攻方洞穴的植被。
● 莲华古城
 ○ 修复了玩家站在A区悬挂的植被后即可避免受到伤害的错误。
● 深海明珠，裂变峡谷
 ○ 修复了英雄技能的地面效果不会出现在玻璃地板上的问题。
● 小镇
 ○ 现在，英雄的壁挂式技能可以被放置于皇冠咖啡厅的建筑上。
生涯系统更新
● 修复了比赛记录会在筛选下拉菜单中显示重复的问题。
社交更新
● 修复了屏蔽玩家功能可以让玩家在比赛过程中屏蔽玩家，并绕过&ldquo;隐藏我的游戏昵称&rdquo;设置的错误。
 
感谢您对《无畏契约》的支持和帮助!
