本次v12.06版本更新内容如下：
常规更新
● 我们更新了对局胜利、失败和平局的视觉效果和音效。
 
英雄更新
我们很高兴幻棱在阵容中找到了自己的定位，但同时我们也注意到，当她使用【光棱闪爆】与其余技能搭配使用时，会制造几乎没有反制空间的局面。
具体来说，我们发现幻棱能够灵活运用她的技能组，用【光棱闪爆】为队友安全锁定敌方玩家，几乎无需冒任何风险。我们认为，决斗者只有主动担负一定风险且承担者主要是决斗者自己时，才是最佳的状态。
将幻棱的【光棱闪爆】技能从立即施放改为装备后，她无法再在空中或接触时立即干扰敌人，除非她愿意冒更大风险。这样一来，幻棱就会更主动地与队友配合，为自己降低风险，而不是单纯将这一技能当作为队友铺垫、供其发挥的工具。
● 幻棱
 ○ 【光棱闪爆】由&ldquo;立即施放&rdquo;调整为&ldquo;装备&rdquo;。
我们正在对【蝰腹】的后端技术进行一些调整。大多数玩家可能不会察觉到明显变化，但我们希望能让【蝰腹】技能表现更稳定，避免在某些地图区域释放失败的问题。大家可以在诸如隐世修所A区高塔、森寒冬港A区管道等地方看到这类改进。
● 蝰蛇
 ○ 更新后，【蝰腹】的化学气雾在地图地形上的扩散方式会更加一致。
● 夜露
 ○ 新增语音
 
外观物品更新
自从一年多前推出&ldquo;盘盘&rdquo;以来，我们收到了许多玩家反馈，认为这类饰品虽然很酷，但用起来总觉得不得劲，因为它们采用的是技能移速，而不是近战武器移速(技能移速只有近战武器移速的90%)。
具体来说，玩家反馈不太愿意装备&ldquo;盘盘&rdquo;，是因为担心在回合中不小心误触，导致关键时刻移速减慢。经过大量测试，我们已经准备好推出这一改动，并设置了一些保障措施(也就是确保所有&ldquo;盘盘&rdquo;都遵循第三人称视角下的竞技公平性原则)。
● 提高装备&ldquo;盘盘&rdquo;时的移动速度，与装备近战武器时的移速一致。这一调整适用于过去已推出和未来将推出的所有&ldquo;盘盘&rdquo;，非常感谢大家的反馈!
 
游戏性能更新
● 我们正在为游戏服务器启用状态同步(推送模式)，以优化性能，并为未来进一步的性能提升打下基础。我们预计游戏客户端不会因此受到任何影响，但如果有发现任何异常，还请大家及时联系客服。
 
玩家进程系统更新
● 战斗通行证新增了分页箭头按钮，更方便切换章节。
● 滚动问题已修复，更新后可以顺利在奖励档位和进度条上进行前后滚动操作。

 ○ 修复了迷核【共振谐律】目标选择界面可能与队友出装界面相互重叠的问题。
 ○ 修复了迷核在释放烟雾后，【声波帷幕】技能放置界面在第三人称视角下短暂滞留的问题。
 ○ 修复了迷核【电音脉冲】可能会卡在地图某些位置且无法被摧毁的问题。
 ○ 修复了暮蝶在阵亡后，没有施放的【霞染】无法取消的问题。
