# 无畏契约正式上线

> **日期**：2023-07-12 ｜ **类型**：大版本
> **公告时间**：2023-07-12 09:00:00

## 更新内容

亲爱的玩家朋友们：
欢迎来到正式上线版本的无畏契约!经过一段时间的&ldquo;无畏终测&rdquo;之后，我们对游戏也做出了不少调整内容，以下为本次正式上线版本中的更新内容。
英雄更新
铁臂
● 惊雷卷地(X技能)
 已更新警告视觉效果，使终极技能的有效范围更加清楚可见。这样一来，玩家可以更简单地看清自己是否会被铁臂的终极技能命中。
尚勃勒● 闪转自如(E技能)
 传送后的武器装备时间从0.7秒减少至0秒
● 贵宾限行(C技能)
 减速范围从4000增加至5000
 陷阱设置时间从4秒减少至2秒
● 孤高火力(X技能)
 射速增加15%
蝰蛇● 燃料恢复
 从每秒恢复5%缩减至每秒恢复3.3%
 燃料耗尽后回满的时间从20秒增加至30秒
其它改动

● 幽影使用离魂(X技能)时的语音将提早播放，让玩家可以更快意识到技能的施放。
● 我们对猎枭的披风动画进行了重制，使其更加流畅自然，同时保留了轮廓贴近身体的设计，避免暴露猎枭的位置。
● 我们对手雷类投掷物轨迹相关的部分代码进行了整理(如猎枭的雷击箭(Q技能)和寻敌箭(E技能)，以及炼狱的燃烧榴弹(Q技能))。
 这些改动有助于防止游戏出现漏洞，方便我们继续为大家带来更多有趣好玩的新功能。游戏的手感应该不会出现明显变化，但如果你发现我们遗漏了任何内容，欢迎告诉我们!
武器更新
升降装置/滑索(绳索)上的武器准确性
我们调整了大部分武器在绳索上的射击误差，使绳索上的战斗更具挑战性。经过这一调整，绳索上的战斗在近距离情况下仍然有效&mdash;&mdash;我们也希望玩家继续利用绳索作为在地图中移动的工具。但在中远距离战斗中，在绳索上移动的可取之处将大大减少。
● 在绳索上的最小射击误差已增加至步行射击误差的65%
步枪从0.8增加至1.3
标配从0.35增加至0.55
狂怒从0.35增加至0.52
鬼魅从0.35增加至0.6
正义从0.35增加至0.78
冲锋枪从0.3增加至0.65
狙击枪和霰弹枪保持不变
● 已增加在绳索上步行和跑步的射击误差，使其与地面步行和跑步的射击误差相匹配。
短炮
看到短炮在游戏中拥有自己的一席之地，我们也十分欣喜。但问题是，这把武器当下实在太过可靠好用了。因此，我们决定提高它的售价，希望玩家在购买它时更加谨慎。我们也对它的伤害进行了一些调整&mdash;&mdash;想一枪解决全副武装的对手，就必须瞄得更准才行。
● 储备弹药从10调整为6
● 价格从$150调整为$300
● 在无衰减区的伤害从12调整为11
● 在第一衰减区的伤害(7米)从8调整为6
狂怒
狂怒在远距离射击的表现过于强大，超出了我们的预期。因此，我们调整了它的射击误差和后坐力，增加了远距离射击的难度，同时保留了狂怒在近距离战斗中的强大威力。
● 最小射击误差从0.45增加至0.65
● 现已调整射击误差曲线
 达到最大射击误差的子弹数从5发调整为6发
● 现已调整后坐力的垂直曲线
 达到最大后坐力的子弹数从5发调整为6发。作为补偿，现已调低整体后坐力。
误差校准
误差校准(也称为中心偏移)是我们用来奖励玩家精准度的工具，它可以使子弹偏向准星的中心点。
这个系统在静止射击时的表现符合预期，却在移动射击时无意中为玩家提供了过多的帮助。我们已大幅减少中心偏移在移动状态中的效果：移动时射击的子弹将随机分布在分散范围内&mdash;&mdash;也就是说，精准命中目标的子弹将会减少。
尽管如此，被跑动射击(和跳跃射击)击败的情况还是会发生。我们认为只要武器合适，在近距离的战斗中出现这种情况，其实是很正常的。但这次针对误差校准做的调整有助于减少这种情况的发生，这一点在远距离射击中的效果尤其明显。
后坐力调整
我们增加了部分武器在跑动射击时的垂直后坐力。换句话说，这些武器在跑动的状态中会变得更难控制。这样一来，应该就能减少跑动时偶然击败玩家的情况。
● 跑动时的垂直后坐力倍数：
 幻影：从1.5增加至1.8
 骇灵：从1.5增加至1.8
 狂徒：从1.5增加至1.8
 狂怒：从1.25增加至1.5
幻影/狂徒的弹药储备
我们希望玩家在使用幻影和狂徒穿射据点常见穿墙点，或在烟雾中进行盲射时，可以加入更多的考量。我们会密切关注调整后的弹药储备，确保这两把武器依旧可以对抗贤者的玉城(C技能)以及其他可击破的障碍物。
● 幻影的储备弹药从90调整为60
● 狂徒的储备弹药从75调整为50

玩家进程系统更新

玩家进程系统更新
● 每日奖励
 这个新功能将会根据你在游戏中的活跃度提供每日奖励。每天进行对局，即可获得节点进度。每个节点都会提供一定数量的经验值，以及全新的游戏内货币&mdash;&mdash;王国币。除了乱斗模式外，进行任何游戏模式都可以获得每日奖励进度。
 王国币可以用于购买饰品、英雄和英雄装备。
● 饰品商店
 使用王国币购买游戏中的饰品，其种类包括：
 ■ 玩家卡面
 ■ 喷漆
 ■ 称号
 ■ 枪支挂饰
● 英雄商店
 英雄商店可以让你更轻松地获得英雄。和往常一样，你可以使用无畏点券或英雄令牌来解锁英雄，而现在你有了第三个选择：使用王国币解锁英雄。
● 英雄招募活动
 每名新英雄上线时，都会开启自己的英雄招募活动。在这些活动中，你将自动获得新英雄的经验值。你将无法使用王国币或英雄令牌解锁新英雄，不过如果你愿意的话，仍然可以使用无畏点券进行解锁。
 如果你在招募活动期间没有获得足够解锁该英雄的经验值，也不用担心&mdash;&mdash;招募活动结束后，该英雄将登陆英雄商店，届时便可如常购买。
● 英雄装备
 所有你喜欢的英雄主题装备都可以使用王国币购买。从现在开始，每名英雄都将有10个英雄装备级别，而不再是原来的10个英雄契约级别。要想获得某名英雄的装备，你首先必须拥有该英雄，然后解锁各个英雄装备级别。
 之前达到5级便可解锁英雄。由于英雄现已被移入英雄商店，达到5级将转而提供一定数量的王国币。但如果你已经拥有该英雄，达到5级将不会提供任何王国币，想了解更多详情，请移步玩家进程系统介绍
