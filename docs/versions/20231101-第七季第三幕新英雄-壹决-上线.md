# 第七季第三幕新英雄"壹决"上线

> **日期**：2023-11-01 ｜ **类型**：大版本
> **公告时间**：2023-10-30 18:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在11月1日1:00-5:00进行停机更新。第七季第二幕排位赛将于10月31日22:00正式结束，停机更新结束后将进入第七季第三幕排位新赛季，排位段位将进行重置。此外，第二幕战斗通行证也将在停机更新开启时正式结束。
本次v7.09版本更新内容如下：
我们即将步入今年的最后一幕&ldquo;破晓时分&rdquo;，新英雄&ldquo;壹决&rdquo;也将隆重登场!快进入游戏试用这位新决斗型英雄吧!别忘了，竞技模式的排位也将重置，此外还有全新的战斗通行证。
除了新赛幕开始时的各种新内容外，我们还推出了以下英雄更新。
 
英雄更新
壹决
●壹决正式上线!
○请前往我们的英雄页面，了解他的各种技能。
○另外，你也可以点此观看>>这位全新决斗型英雄的英姿
 
零、斯凯、黑梦和雷兹
这次更新中，我们想要解决哨卫英雄(尤其是零)和其他一些英雄之间的能力平衡问题。哨卫英雄往往会在战斗开始前精心布置一番，道具却被雷兹、斯凯、黑梦这样的英雄意外摧毁;不仅如此，哨卫想在接下来的对局中重新部署它们更是难上加难。这次的版本中，我们将调整零的震慑绊线(C)，让这类互动对他更有利。此外，我们还希望让敌方英雄使用他们的技能清理哨卫辅助物时需要更加精准、更有针对性。
 
零
●这些调整可以迫使攻方英雄主动摧毁绊线、打破零的布置，并让零与黯兽(C)和辟林之虎(Q)等技能互动时处在更加有利的位置。此外，我们还稍微提升了陷阱阻碍敌人的效力，以便让敌人对绊线更加重视。
○震慑绊线(C)
■ 陷阱困住敌人与震荡敌人的间隔从3秒降低至1.5秒。
■ 震荡敌人后，或陷阱内的敌人被击败后，震慑绊线(C)将不再自毁，而是会在0.5秒后重新部署，可以再次困住敌人。
■ 被陷阱命中后减速持续时间从0.75秒提升至2秒。
以下对斯凯和黑梦的调整，也是为了丰富绊线布置的战术深度。
 
斯凯
●辟林之虎(Q)
○调整了辟林之虎的碰撞体积，使其能从中等高度的震慑绊线下方通过。此调整不会影响武器伤害的命中范围。
黑梦
●黯兽(C)
○调整了黯兽(C)的碰撞体积，使其可以越过脚踝高度的绊线、并从头部高度的绊线下方通过。此调整不会影响武器伤害的判定范围。
 
雷兹
现在，雷兹必须更精准地使用彩雷飞溅(E)，才能对敌人造成伤害或破坏敌方陷阱。此外，雷兹在使用惊喜翻腾(Q)时也需要更加深思熟虑，在机动性和伤害这两者之间做出选择。
○彩雷飞溅(E)
■主手雷的爆炸范围从6米减少至5.5米。
■次手雷的爆炸范围从6米减少至5.25米。
■主手雷爆炸造成的最低伤害从15降低至1。
■次手雷爆炸造成的最低伤害从15降低至1。
■对敌方设备的伤害倍率从250%降低至100%。
○惊喜翻腾(Q)
■在充分激活之前，炸药包将无法造成伤害。
■炸药包的充分激活时间从0.5秒增加至1.5秒。
 
武器更新
判官
以下改动旨在削弱判官跑打时的效能，使其更符合蹲射型霰弹枪的定位。我们还减少了它的弹匣容量，希望可以借此增加对手抓住上弹时机进行反制的机会，同时也让使用判官的玩家在面对多名对手时，必须提高子弹的利用效率。
●判官
○最大弹匣容量从7发减少至5发
○跳跃射击扩散从1.25增加至2.25
○奔跑射击扩散从0.10增加至0.75
 
玩家行为更新
●新增了一个选项：在游戏中举报其他玩家时，可选择静音/屏蔽该玩家。
 
错误修复
通用
●修复了一部分玩家的硬件配置会导致登录时出现白屏的问题。
玩法系统
●修复了脱离绳索时会发出脚步声的偶现问题。
