# 第八季第二幕 新英雄"暮蝶"上线

> **日期**：2024-03-06 ｜ **类型**：大版本
> **公告时间**：2024-03-05 20:59:45

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 3月6日1:00~5:00进行停机版本更新，第八季第一幕排位赛将于3月5日 22:00正式结束，停机更新结束后将进入第八季第二幕排位新赛季，排位段位将进行重置。此外，第八季第一幕战斗通行证也将在停机更新开启时正式结束。
 
本次v8.03&v8.04版本更新内容如下：
大家好!欢迎来到第八季第二幕!这次版本中，我们对尚勃勒进行了一些调整，同时推出了铁臂的语音更新等精彩内容，我们还为游戏进行了全面性的错误修复，其中也包括K/O的零点嗅探(E)有时无法准确报告信息的问题，祝你玩得愉快!
 
英雄更新
铁臂
● 我们更新了铁臂的语音，并添加了他与钢锁、盖可和海神的互动台词。
尚勃勒
我们近期的关注重点是调整和明确各个哨卫英雄的优劣势。本次更新旨在提升尚勃勒使用其独有武器进行防守的能力。通过这些调整，玩家应该能更自由地购买金牌猎头(Q)来节省资金和代替其他手枪。此外，尚勃勒的终极技能对比冥驹也会拥有更明显的强度优势。
● 金牌猎头(Q)
○ 价格从150减少至100
● 孤高火力(X)
○ 射速从0.7增加至0.9
 
模式更新
● 我们为靶场的训练机器人添加了角色头像和小地图图标。
 
商店更新
电竞商店
● 电竞商店现已上线!
○ 你可以通过全新的电竞商店购买VCT队伍礼包，支持自己喜爱的队伍。
○ 参赛队伍将从相应礼包的出售利润中获得50%。
○ 每个礼包都包含一把标配手枪、一个枪械挂饰、一张玩家卡面，以及一款喷漆。
 
随着马德里大师赛的临近，我们还对游戏内的电竞赛事中心进行了几项更新：
● 启点赛落幕、各支参赛队伍终于拿到马德里大师赛的门票时，赛事中心的国际赛事页面便会解锁，供玩家查看参赛队伍、赛程以及全新赛制。
● 玩家可以在瑞士轮分组的页面查看小组赛情况、观看战队晋级季后赛的全过程。
 
错误修复
英雄
● 修复了一个问题：当玩家在芮娜的睥睨(C)的眼球刚进入可攻击状态时便将其摧毁，在第三人称视角下，会短时间内被错误地显示为视野仍受限制的状态。
● 修复了K/O的零点嗅探(E)有时无法准确报告信息的问题。如果你还有发现其它问题，欢迎向我们提出反馈。
● 修复了玩家被贤者的再起(X)复活时，角色会在动画结束时被轻微推动的问题。
● 修复了贤者的玉城(C)角落可以被子弹击穿的问题。
 
竞技模式
● 修复了比赛总结页面的每回合击败数有时无法正确向上取整的问题。
 
玩法系统
● 修复了记分板页面中终极技能使用次数会被较长用户名遮挡的问题。
● 修复了部分技能，例如奇乐的全面封锁(X)超出小地图部件的问题。
 
地图
● 日落之城
○ 调整了A区拐角的栅栏，以解决从顶部射击时出现的问题。
○ 修复了玩家可以跳到A区大厅电话亭上的问题。
○ 修复了攻方可以从中区破坏零在B区大道部署的震慑绊线(C)的问题。
 
电竞功能
● 修复了电竞赛程页面不会自动跳转到当前日期的问题。
● 修正了&ldquo;入围赛小组赛&rdquo;分组中显示重复信息的视觉错误。
 
感谢您对《无畏契约》的支持和帮助!
