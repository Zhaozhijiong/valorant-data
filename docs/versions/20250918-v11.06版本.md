# v11.06版本

> **日期**：2025-09-18 ｜ **类型**：小版本
> **公告时间**：2025-09-17 11:11:49

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 9月18日 8:00进行不停机版本更新，更新过程中大家可以在游戏内正常进行对局，若有偶现的匹配不可用请稍作等待即可恢复。为您带来的不便我们深表抱歉。
本次v11.06版本更新内容如下：
游戏性能更新
● 原始输入缓冲设置现已移除，无法进行手动设定。现在起，该设置将始终对所有玩家启用，以提升游戏性能。
错误修复
● 英雄
○ 我们修复了一个极其罕见的错误：在某些非常特殊的情况下，夜露和芮娜进入隐形状态后，会在隐形效果结束时重新出现在其初始位置。
已知问题
● 在某些特定情况下，王国币商店缺失1格购买道具的问题，将在v11.07进行修复
● 神中神罚系列皮肤 彩蛋无法触发的问题，将在v11.07进行修复
● 末日泡泡瞄准镜爱心跳动特效消失的问题，目前仍在定位中，将尽快修复
此外，关于游戏回放功能，我们在先前的官方公告进行了预告，将在10月9日的版本更新中正式更新参考原文请见此处
感谢您对《无畏契约》的支持和帮助!
