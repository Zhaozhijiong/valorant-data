# v7.00b版本

> **日期**：2023-07-26 ｜ **类型**：小版本
> **公告时间**：2023-07-25 18:31:59

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在7月26日上午9:00进行不停机更新，更新过程中大家可以在游戏内进行正常体验。更新完成后，游戏内即可显示新增的游戏内容。
 
本次更新内容如下：

 
1.新增1张地图：莲华古城将加入竞技模式和其他模式地图池中。

 
2.新增3名英雄：
盖可：西海岸小伙&ldquo;盖可&rdquo;随身带着一群调皮捣蛋的小怪兽。这些小跟班们负责冲在战斗的最前方，给敌人制造各种麻烦。等到盖可追上来后，它们还能回到他身边，然后再次出击。
钢锁：来自北欧的特工&ldquo;钢锁&rdquo;配备着多种尖端纳米纤维武器，她擅长监听战场动态和阻碍对手移动。一旦敌人遭到锁定，将面对她凌厉无情的攻势并难逃一劫。
黑梦：&ldquo;黑梦&rdquo;是来自小亚细亚地区的赏金猎人，她能够操纵纯粹的噩梦能量，揭开他人心底潜藏的恐惧和秘密。她会如梦魇般对敌人穷追不舍，然后在黑暗中将其摧毁殆尽。
前往查看英雄技能详情：游戏资料>>>
 
3.新增1个游戏模式：爆能快攻模式现已加入游戏。任何等级玩家均可游玩。
《无畏契约》中节奏更快、更休闲的游戏模式。与匹配模式拥有相同的规则，地图中加入了强化法球和随机武器装备可以夺取。先赢下4个回合的一方即可获胜。
感谢您对《无畏契约》的支持和帮助!
