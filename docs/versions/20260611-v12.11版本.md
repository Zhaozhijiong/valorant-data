# v12.11版本

> **日期**：2026-06-11 ｜ **类型**：小版本
> **公告时间**：2026-06-10 14:54:46

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 6月11日 1:00-5:00 进行停机版本更新，竞技模式将于 6月10日 23:00开始暂时关闭，停机更新结束后将重新开放，为您带来的不便我们深表抱歉。
本次v12.11版本更新内容如下：
错误修复
●英雄
 ○修复了在裂变峡谷中，英雄在滑索上掉落爆能器时，会频繁重复触发爆能器拾取语音的问题。
 ○修复了在左手模式下，斯凯、霓虹和黑梦的HUD特效有时会偏移到屏幕中央的问题。
 ○修复了迷核用电音脉冲为未受伤的队友治疗时会获得助攻的问题。
 ○修复了蝰腹会在某些特定位置卡住、无法扩展的问题。
 ○修复了贤者的逢春在购买阶段无法使用的问题。
 ○修复了在快速切换技能后，迷核的电音脉冲无法正常切换状态的问题。
 ○修复了暮蝶的化蝶在技能可用或持续时间结束时，第一人称和第三人称音效未正常播放的问题。
 ○修复了雷兹的惊喜翻腾无法对可摧毁的敌方技能造成伤害的问题。
 ○修复了盖可的可回收技能球体在使用无敌超鲨后会消失的问题。
●地图
 ○修复了在微风岛屿上，位于A区大道大型箱子后方、处于视野盲区的敌人仍能被多个英雄技能锁定的问题。
 ○微风岛屿将回归匹配队列。
 
已知问题
●英雄
 ○我们已经注意到幻棱在亚海悬城可以把她的溯流回光置于屋顶上的问题。
●地图
 ○我们已经注意到莲华古城存在门有时无法打开的问题。
 
感谢您对《无畏契约》的支持和帮助!
