# v11.09版本

> **日期**：2025-10-30 ｜ **类型**：小版本
> **公告时间**：2024-10-29 18:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 10月30日 8:00 进行不停机版本更新，更新过程中大家可以在游戏内正常进行对局，若有偶现的匹配不可用请稍作等待即可恢复，为您带来的不便我们深表抱歉。
本次v9.08a版本更新内容如下：
错误修复
英雄
● 捷风
 ○ 修复了捷风在使用逐风技能穿进瞬云(C)或者炼狱的空投烟幕(E)时会导致视野受限的问题。
 ○ 修复了捷风在莲华古城时，使用逐风(E)后碰到正在旋转的旋转门会持续反弹的问题。
 ○ 修复了捷风在亚海悬城A窗口处使用逐风(E)冲破窗户后，技能动作会重复释放的问题。
 ○ 修复了捷风使用逐风(E)技能进入持续伤害技能范围时只会受到首次伤害的问题。
 ○ 修复了捷风使用逐风(E)可以从外部打开源工重镇传送门的问题。
● 斯凯
 ○ 修复了斯凯使用辟林之虎(Q)可以从外部打开源工重镇传送门的问题。
 
感谢您对《无畏契约》的支持和帮助!
