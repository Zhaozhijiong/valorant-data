# v9.01版本

> **日期**：2024-07-18 ｜ **类型**：小版本
> **公告时间**：2024-07-17 21:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 7月18日 8:00 进行不停机版本更新，更新过程中大家可以在游戏内正常进行对局，若有偶现的匹配不可用请稍作等待即可恢复，为您带来的不便我们深表抱歉。
本次v9.01版本更新内容如下：
模式更新
● 武装升级
 ○ 由于存在错误，从9.01版本开始，武装升级将被禁用，并于9.03版本回归。
武器更新
● 更新了莽侠及其各皮肤系列的动画，使武器准备就绪时的效果更加明显。
组件更新
● 无畏契约定制版安全反外挂组件全面升级，进一步加强针对DMA硬件外挂、AI外挂、内存外挂的检测能力。
错误修复
通用
● 修复了霓虹可以通过手动输入装备动作，使滑行结束时的装备速度比预期更快的问题。
玩法系统
● 修复了挂机玩家可以发起投降投票的问题。
● 修复了零退出战术监控后，观众视角会发生短暂卡顿的问题。
● 修复了即使在设置中关闭选项后，聊天中依旧会显示战术呼叫的问题。
● 修复了即使在设置中关闭弹道显示后，拾起的枪械依旧会显示弹道的问题。
● 修复了观众和观看者无法看到贤者和暮蝶复活的问题。
● 修复了自定义游戏模式中，爆能器爆炸触发的自动重生会导致性能下降的问题。
地图
● 幽邃地窟
 ○ 清理了多处可供零放置战术监控的位置，以防止出现视觉问题或有违设计意图的放置情况。
 ○ 改进了皮蛋在A区部署爆能器的路径。
 ○ 整理了地图上多个位置技能和玩家的碰撞逻辑。
 ○ 修复了启用某些设置时，小地图的方向可能会颠倒的问题。
 ○ 修复了在A区从地图上掉落时出现视觉错误的问题。
 ○ 修复了蝰腹在A区扩散范围可能超出预期的问题。
已知问题
社交
● 组队房间发生变化时，聊天记录可能会出现&ldquo;&rdquo;的错误信息。
 
感谢您对《无畏契约》的支持和帮助!
