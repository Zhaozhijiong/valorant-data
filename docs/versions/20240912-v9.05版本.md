# v9.05版本

> **日期**：2024-09-12 ｜ **类型**：小版本
> **公告时间**：2024-09-11 14:16:34

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在9月12日1:00~5:00进行停机版本更新，竞技模式将于9月11日 22:00开始暂时关闭，停机更新结束后将重新开放。
下面为大家带来的是9.05版本更新公告。有什么新内容?问得好，我们对几名英雄进行了更新，比如星礈的星体增加到了5颗，尚勃勒闪转自如的半径也获得了提升。
同时我们也对游戏服务器集群进行了新增和扩容，大家可以在游戏内选择到更多对战节点了。点击查看>>
在最后，大家也可以查看第九季其余版本的推出时间表。请注意，版本更新时间可能由于各种原因发生变化，所以这些版本在实际更新时间上可能会有一些出入。
本次v9.05版本更新内容如下：

英雄更新
幽影
 ● 我们更新了幽影的语音，并丰富了他与蝰蛇、暮蝶、壹决和维斯的互动台词。
尚勃勒
 ● 闪转自如：传送半径从13米增加至18米
 ○ 尚勃勒需要一点小小的助力，让他可以在地图上更安全有效地利用闪转自如争取更多空间。增加闪转自如的传送半径，可以提供更多的准备空间，让尚勃勒得以更加激进地前压、从敌人意想不到的角度发起进攻。
星礈
 ● 星体数量：从4增加至5
 ○ 在7.04版本中，我们对星礈的能力进行了一些平衡性调整，削弱了她的重力之阱，同时增强了她的新星脉冲和宇宙分裂，这导致她难以与其他控场英雄匹敌。鉴于星礈必须在&ldquo;履行控场的核心职责&rdquo;和&ldquo;使用其它技能&rdquo;之间做出选择，我们希望以下改动可以让她更自由地使用其它技能，同时不影响她在整个回合中的封烟能力。
作战强化
 ● 这些年来，我们经常收到玩家针对作战强化的反馈，表示这个效果(比如芮娜的女皇旨令)会在连射时产生干扰，导致玩家很难准确命中目标。经过本次改动之后，即使是在作战强化的作用下，玩家依旧可以凭借自己在正常状态下练就的肌肉记忆，有效地操纵枪械。注意：这个改动仅会影响强化效果对后坐力的调整，不会影响强化效果带来的降低扩散效果。
武器更新
战神
 ● 回退之前对蹲伏效益的削弱，从当前的25%恢复到40%
 ○ 蹲伏的效果将有所恢复，与奥丁不相上下。
 ● 精准击败的倍数从2.4调整为2.5
 ○ 利用战神在30米内进行两次精准射击即可击败敌人，而之前则会造成144伤害。
这些改动的目的，是为了让战神精准射击的伤害与同类武器更加一致，同时增强其对抗多个敌人的能力，让玩家可以有效坚守防线。
游戏性能更新
 ● 优化了线程逻辑和磁盘上的文件排序，以缩短游戏启动和进入游戏的加载时间。请注意：这个改动会导致新版本的下载和安装时间稍有提升。
玩家行为更新
 ● 我们更新了现有的竞技模式，并将其扩展到了所有的团队模式。也就是说，因违规行为而受到惩罚的玩家将受到限制，无法参与任何团队模式。
错误修复
地图
 ● 幽邃地窟
 ○ 修复了玩家可以落在地图上某个超出边界的边缘处的问题。
 ● 莲华古城
 ○ 对地图进行了小幅的美术设计调整。
 ● 森寒冬港
 ○ 修复了玩家可以通过一个缺口从中区锅炉穿射A区管道内门框的问题。
 ● 日落之城
 ○ 修复了B区奶茶店上方可伸缩屋顶的一个缺口。
 ○ 修复了中区坡顶的箱子，使其显示正确的子弹穿透痕迹。
 ● 靶场
 ○ 移除了远景中的一个占位物体。
已知问题
英雄
● 不死鸟
 ○ 火热手感(E)在整个持续时间内只能为不死鸟恢复 25 点生命值(原为50)
● 炼狱
 ○ 天基光束(X)的音频声源可以穿过地图墙壁，声音在左右耳机之间切换
