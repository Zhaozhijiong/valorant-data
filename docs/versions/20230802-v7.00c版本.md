# v7.00c版本

> **日期**：2023-08-02 ｜ **类型**：小版本
> **公告时间**：2023-08-01 12:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在8月2日 5:00进行停机维护和版本更新，预计更新结束时间为8月2日9:00。排位模式将在停机维护开始前一小时于4:00关闭，维护结束后正常开启。请各位玩家合理规划好自己的游戏时间，为您带来的不便我们深表抱歉。
 
本次更新内容如下：
地图更新
裂变峡谷将加入除竞技模式和团队乱斗模式以外所有模式地图池中。

 
玩家行为系统更新
● 受到队伍语音禁言的用户，将同时受到房间语音禁言。
 
商店
《双城之战 》系列礼包将在8月3日正式上架商店
礼包售价：1670无畏点券
包含内容：正义，挂饰，卡面，喷漆
售卖时间：2023年8月3日5点至2023年8月17日5点
下架后不会出现在现售商店和夜市之中
 
错误修复
一般
● 修复了在团队乱斗和武装升级模式的热身阶段中，喷漆轮盘可能无法显示的问题。
● 修复了当玩家站在布署区边缘时，爆能器拆除动画会突然停止并重新开始的问题。
● 修复了当输入设置为&ldquo;按住&rdquo;时，无法切换步行的问题。
● 修复了当准星方案数量达到最大时，&ldquo;复制方案&rdquo;按钮不会变灰的问题。
 
英雄
● 修复了一个问题：当幽影在传送前的启动过程中被K/O的零点嗅探(E)或钢锁的断魂索道(X)击中时，他的离魂(X)和践影(C)无法被正常取消。此外，我们还添加了取消传送的视觉效果。
● 修复了K/O的零点嗅探(E)在完成范围压制后，匕首柄仍然停留在环境中的问题。
● 修复了当盖可的顽皮搭档(Q)在拆除其探测区域内的爆能器时，钢锁的声感陷阱(Q)有时会无法触发的问题。
● 修复了尚勃勒的闪转自如(E)在传送初始位置的视觉效果错误。
● 修复了当玩家被钢锁的断魂索道(X)困住时，爆能器爆炸无法正常击败玩家的问题。
● 修复了雷兹的晚安焰火(X)击中被钢锁的断魂索道(X)困住的玩家时，无法正常爆炸的问题。
● 修复了范围持续伤害技能(如不死鸟的火热手感[E])无法伤害钢锁的阻域屏障(E)的问题。
● 修复了炼狱的天基光束(X)无法伤害钢锁的断魂索道(X)形成的茧的问题。
● 修复了斯凯在交换阵营时，会额外获得一段引路之隼(E)充能的问题。
 
地图
● 修复了一个当玩家在施放受控技能(如猎枭的枭型无人机[C])通过源工重镇B区传送器时，传送音效会被切断的问题。
