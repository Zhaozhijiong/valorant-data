# v7.00a版本

> **日期**：2023-07-19 ｜ **类型**：小版本
> **公告时间**：2023-07-18 12:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在7月19日上午9:00进行不停机更新。更新过程中大家可以在游戏内进行正常体验。更新完成后，游戏内即可显示新增的游戏内容。
本次更新内容如下：

1. 新增1张地图：
微风岛屿将加入竞技模式和其他模式地图池中。

2. 新增3名英雄：
夜露：来自东亚的&ldquo;夜露&rdquo;能够直接撕裂现实空间，无声无息地渗透敌人的防线。他在战斗中喜欢虚实结合，在敌人尚未猜到他的位置时发动突然袭击。他在游戏内的定位是决斗。
控场：星礈：来自非洲大陆的&ldquo;星礈&rdquo;可以操控宇宙能量来重塑战场。她可以进入星界形态，以超脱凡界的战略眼光洞悉战场，抢在敌人行动之前便占得先机。她在游戏内的定位是控场
先锋：K/O：他是一台战争机器，他被制造出来只有一个目的：消灭源能者。他的能力可以压制敌人的技能，为自己与队友制造战术优势。他在游戏内的定位是先锋
前往查看英雄技能详情：游戏资料-VALORANT《无畏契约》官方网站-腾讯游戏
3. 新增1个游戏模式：
武装升级模式现已加入游戏。任何等级玩家均可游玩。
这是一个快节奏的团队竞赛模式，你需要和队伍一起，利用全部12件武器或技能不断击倒敌人并升级武器，任何一方首先完成整个挑战，即可获取团队胜利。
感谢您对《无畏契约》的支持和帮助!
