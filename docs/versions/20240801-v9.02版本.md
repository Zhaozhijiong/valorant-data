# v9.02版本

> **日期**：2024-08-01 ｜ **类型**：小版本
> **公告时间**：2024-07-31 21:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 8月1日 8:00进行不停机版本更新，更新过程中大家可以在游戏内正常进行对局，若有偶现的匹配不可用请稍作等待即可恢复，为您带来的不便我们深表抱歉。

本次v9.02版本更新内容如下：
常规更新
● 先前为主机平台提供的新基础训练(教程)和靶场功能，现已在PC平台上线!
 ○ 所有新玩家都必须完成这项教程，并且可以自行选择是否参与机器人训练比赛。
 ○ 现有玩家则可以通过练习菜单进入基础训练和靶场。
● 英雄选择界面更新，现在你可以更加快捷的筛选需要选择的英雄类型
玩法系统更新
● 战斗记录
 ○ 视觉效果全面更新!游戏内的战斗记录将以新面目登场。
 ○ 战斗记录在购买阶段将默认可见，但玩家依旧可以选择将其显示或隐藏。
玩家行为更新
● 行为干预更新：在通讯中行为不当的玩家将受到更严厉的惩处。
错误修复
英雄
● 霓虹
 ○ 修复了霓虹的命中判定框在滑行时可能会略微偏移的问题。
玩法系统
● 修复了技能HUD在阵亡镜头中持续显示的问题。
地图
● 幽邃地窟
 ○ 修复了爆能器可能会卡在地图外某些边缘区域的问题。
 ○ 修复了幽影在中区坡底特定位置进行传送可能会直接阵亡的问题。
 ○ 修复了多个视觉错误。
● 日落之城
 ○ 现在起，玩家将无法再跳到A区巷道的高箱上。
已知问题
● 玩法系统
 ○ 战斗记录的额外详情窗口缺少了&ldquo;武器/技能&rdquo;、&ldquo;伤害&rdquo;和&ldquo;命中&rdquo;标题。
● 靶场
 ○ 靶场射击挑战设置机器人连续消灭50和消灭100时，无计时器显示。
● 自定义游戏
 ○ 锦标赛模式下，教练视角无法正常查看队员选择英雄的界面。
以上已知问题都将在之后的版本更新中解决。
 
感谢您对《无畏契约》的支持和帮助!
