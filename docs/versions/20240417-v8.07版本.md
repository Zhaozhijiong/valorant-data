# v8.07版本

> **日期**：2024-04-17 ｜ **类型**：小版本
> **公告时间**：2024-04-16 18:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 4月17日1:00~5:00进行停机版本更新，竞技模式将于4月16日 23:00开始暂时关闭，停机更新结束后将重新开放，请合理安排您的游戏时间。
 
本次v8.07版本更新内容如下：
常规更新
● 我们对交互提示的可读性进行了更新，增加了对比度，使其在游戏中更便于阅读。提示文本已经简化，武器提示也不再显示皮肤系列名称。
 
英雄更新
幽影
● 从现在开始，处于离魂(X)阴影形态下的幽影，无需取消技能即可拾取爆能器，并与其它可用物品(比如门)进行交互。这个调整的目的，是为了让这些互动更加直观、意图更加明确。
玩法系统更新
● 即使延迟受到影响，闪光弹的表现也会更加一致。
 
错误修复
通用
● 伤害显示
● 我们修复了非整数伤害会导致HUD界面承受总伤害显示错误的问题。这个错误曾引发多个问题，比如近距离使用标配武器打中带甲目标的躯干时，伤害显示为25而不是26，以及在某些情况下，使用暮蝶的虹吸(C)治疗后，生命值显示为151。
● 备注：本调整仅限视觉错误修复，围绕伤害的基础玩法没有发生改变。
 
英雄
● 尚勃勒
● 修复了尚勃勒可以在非设计意图的地点放置贵宾限行(C)的错误。
● 暮蝶
● 试验性的修复了暮蝶的身体会在阵亡后仍保持直立的错误。
● 修复了暮蝶的化蝶(X)无法推进&ldquo;使用终极技能&rdquo;每周任务的进度，比赛数据会误报为0次施放的问题。
● 修复了在阵亡后使用暮蝶的霞染(E)不会在比赛数据中显示的问题。
● 修复了在对暮蝶虹吸(C)临时生命值造成伤害后不会在战斗记录中显示的问题。
● 修复了暮蝶在施放化蝶(X)期间，在受到压制时会突然改变瞄准方向的问题。
● 修复了暮蝶在使用化蝶(X)时，可能以没有主要武器的状态复活的问题。
● 修复了暮蝶装备霞染(E)后，高速向上或向下瞄准时，头部和手臂命中判定框(hitbox)可能发生偏移的问题。
● 修复了暮蝶装备霞染(E)后，蹲伏时也会发生上述同样错误的问题。
● 修复了暮蝶的整蛊(Q)在战斗记录中显示不正确技能图标的问题。
● 试验性的修复了暮蝶激活虹吸(C)并受到坠落伤害时，技能的HUD界面有时会显示总生命值>150的错误。
● 修复了在暮蝶的烟雾边缘移动时，视觉不会平滑过渡，而是发生闪烁的问题。
● 修复了暮蝶阵亡时，观看暮蝶的阵亡队友或观看者会跳过阵亡镜头仪式的问题。
● 修复了暮蝶的整蛊(Q)可能会在极少数情况下导致客户端故障的问题。
 
外观物品
● 武器与皮肤音频
●我们收到了几份关于皮肤音频错误的报告，现已修复：
● 紫阙金琅标配
● 冰点凝冻标配
● 此外，我们也收到了其它几个枪械/皮肤(标准/默认 幻影、般若假面 幻影、侦察力量 幻影等)音频出现问题的报告，但我们已核实这些枪械/皮肤的音频运作正常。
● 如果这些枪械，或任何其它第一人称音频在耳机上听起来与8.05版本之前不同，则可能是由玩家在《无畏契约》音频设置中的扬声器配置导致的。如果Windows将你的USB耳机识别为多声道的环绕声设备，而你又在《无畏契约》的音频设置中选择了&ldquo;自动检测&rdquo;，就有可能导致音频出现问题。
● 如果你使用耳机收听，并选择了&ldquo;自动检测&rdquo;，且未启用空间音频，那你的扬声器配置应显示为2.0。如果显示的是其它声道设置，你可以将《无畏契约》扬声器配置设回立体声，或在Windows中启用空间音频，以解决这个问题。
 
玩法系统
● 修复了快捷指令菜单绑定到数字键后，尝试激活指令时会产生冲突的问题。
 
已知问题
● 靶场
● 进入靶场的加载界面显示错误的文本信息，我们会在后续版本提供修复。
感谢您对《无畏契约》的支持和帮助!
