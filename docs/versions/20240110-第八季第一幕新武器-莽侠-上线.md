玩法系统更新
从8.0版本开始，《无畏契约》将支持第三方耳机空间化软件。
&ldquo;空间音频(Spatial Audio)&rdquo;可以在耳机中模拟环绕声。该软件将对音频进行处理，帮助你在耳机中区分前后方甚至上下方的声音，比如辨别这些脚步声是在前还是在后。我们荣幸地向大家宣布，8.0版本将正式支持包括第三方在内的空间音频解决方案!这将在《无畏契约》音频设置中已有的HRTF选项之外，为你带来更多选择。7.06版本时，我们尚不支持第三方空间化软件，对音频引擎的修改经常为使用第三方空间化软件的用户带来麻烦。如果在7.06版本时在Windows设置中启动第三方空间化软件，音量就会变得紊乱。当时，我们只能让受影响的用户暂时关闭第三方空间化软件，解决这个问题。随后，我们在7.07版本中进行了仅限立体声的修复，与空间音频兼容，但无法模拟环绕声。在8.0版本中，《无畏契约》音频设置中的&ldquo;扬声器配置&rdquo;默认为立体声，选择将&ldquo;扬声器配置&rdquo;设置为&ldquo;自动检测&rdquo;，即可享受空间音频解决方案提供的所有功能。
 
如何在《无畏契约》中体验空间音频?
●步骤1：打开《无畏契约》的音频设置，将&ldquo;扬声器配置&rdquo;从&ldquo;立体声&rdquo;改为&ldquo;自动检测&rdquo;。

●步骤2：在Windows设置中打开&ldquo;空间音频&rdquo;。打开声音控制面板，右键单击播放设备，选择&ldquo;属性&rdquo;，然后点击&ldquo;空间音效&rdquo;选项卡，启动空间化软件，并选择不同的空间声音格式。

如何关闭第三方空间化软件?
●步骤1：要在Windows中关闭第三方音频空间化(也称空间音效)，请打开声音控制面板，右键点击你的播放设备，选择&ldquo;属性&rdquo;，转到&ldquo;空间音效&rdquo;页面，在这里关闭空间化软件。

注意：有些外设自带硬件制造商提供的空间化软件。这种情况下，玩家可能无法通过Windows声音控制面板查看并启动&ldquo;空间音频&rdquo;，但可以通过该自带软件启动。
 
●步骤2：打开《无畏契约》的音频设置，将&ldquo;扬声器配置&rdquo;从&ldquo;自动检测&rdquo;改为&ldquo;立体声&rdquo;。

我启动了第三方空间音频软件，但在8.0版本中的效果很糟糕，该怎么办?
●《无畏契约》的&ldquo;扬声器配置&rdquo;默认为&ldquo;立体声&rdquo;，与8.0版本的&ldquo;空间音频&rdquo;不兼容。将《无畏契约》的&ldquo;扬声器配置&rdquo;更改为&ldquo;自动检测&rdquo;，即可让&ldquo;空间音频&rdquo;顺利运行。
 
可以使用虚拟7.1声道USB耳机吗?
●程序现支持基于USB的虚拟7.1声道耳机。请提前安装耳机制造商提供的所有音频软件和驱动程序，以确保耳机正常工作。
 
我已经把《无畏契约》的&ldquo;扬声器配置&rdquo;设置为&ldquo;自动检测&rdquo;，但没有在Windows设置中启动&ldquo;空间音频&rdquo;。我现在用USB耳机进行游戏，却听不到自己的英雄语音，也听不到前方或后方传来的音效。该怎么办?
●如果你在游戏中遇到这种情况，有两种快速的解决方法。第一，在安装耳机驱动程序之前，将《无畏契约》&ldquo;扬声器配置&rdquo;设置为&ldquo;立体声&rdquo;;第二，在Windows音频设置中启用&ldquo;空间音频&rdquo;(Windows自带Windows Sonic)。但切勿同时进行这两种设置，只能选择其中之一。原因在于，某些USB耳机会被Windows识别为5.1或7.1设备，但这些耳机必须通过驱动程序才能把6或8个声道混为立体声。如果没有安装所需的驱动程序，就无法从中央或环绕播放声音，耳机便不会发出响声，这部分声音将会丢失。经过我们测试，安装耳机制造商提供的音频软件和驱动程序就能解决这一问题。
 
我喜欢以前游戏中的HRTF效果，以后还能继续用吗?
●现有的HRTF选项仍会保留。如果你已在《无畏契约》设置中启动HRTF，登录8.0版本后会保持原样。
 
我之前启用了HRTF，但想改用其他空间音频软件，该怎么办?
●如果你在《无畏契约》中将&ldquo;扬声器配置&rdquo;更改为&ldquo;自动检测&rdquo;，并在电脑系统中启动&ldquo;空间音频&rdquo;，《无畏契约》将为你启用空间音频并关闭HRTF。
 
我使用的是蓝牙耳机，打开空间化软件时音频总是断断续续。该怎么办?
●我们在测试中也遇到了这个问题，关闭蓝牙耳机的&ldquo;免提通话&rdquo;功能就可以解决。请注意，关闭此功能会禁用耳机的内置麦克风。该设置可在&ldquo;设备和打印机&rdquo;-(你的耳机)-&ldquo;属性&rdquo;-&ldquo;服务&rdquo;中更改。
 
我用的是扬声器，该怎么办?
●HRTF和空间音频是专为耳机设计的。如果你使用扬声器进行游戏，请关闭HRTF和空间音频。
 
游戏今后是否还会支持单声道的无障碍功能?
●支持。但请注意，单声道功能会利用左右声道之间的时间差异和频谱差异，因此无法使用HRTF或空间化技术进行混音。即使你在系统设置中启用了&ldquo;空间音频&rdquo;，游戏也会自动绕过这一功能，不会对单声道选项产生任何影响。打开或关闭单声道选项时，可能需要重新启动游戏才能使更改生效。
 
我尝试了第三方空间化软件，但感到头晕或恶心。这是怎么回事?
●虽然很少见，但HRTF和空间音频技术的确可能会导致部分人群出现这类症状。如果你使用的空间音频软件让你出现了这些症状，请将其关闭，或尝试其它空间音频解决方案。
 
空间音频会影响竞技公平性吗?
●空间音频用到了HRTF(头部相关传递函数)技术，而所有采用HRTF的软件都基于解剖学模型，例如耳朵之间的距离、肩膀到耳朵的距离、耳软骨的形状以及许多其它数值。这些数值用于模拟头周声音的时间和频谱差异，并模仿大脑对周围声音进行三维定位的方式。由于声速的原理，从右侧传来的声音会先到达右耳，稍后到达左耳。我们的大脑会解读这些细节，然后告诉我们声音来自哪里。每个人习惯听到的声音效果都取决于其头部结构。对你而言，与你头部结构相匹配的HRTF模型听起来最自然。如果你使用的HRTF配置与自己的头部结构不匹配，可能很难分辨声音是在前面还是后面。我们很高兴能在8.0版本中为大家带来更多的空间化软件选项。我们并不认为某个特定的HRTF解决方案会带来竞技方面的优势&mdash;&mdash;说到底，它只是个人偏好而已。
