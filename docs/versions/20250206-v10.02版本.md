# v10.02版本

> **日期**：2025-02-06 ｜ **类型**：小版本
> **公告时间**：2025-02-05 12:06:37

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 2月6日 8:00 进行不停机版本更新，更新过程中大家可以在游戏内正常进行对局，若有偶现的匹配不可用请稍作等待即可恢复，为您带来的不便我们深表抱歉。
本次v10.02版本更新内容如下：
大家新年好!希望在段位保护机制发布后，大家在竞技模式中都能越战越勇。
这次为大家带来的是一次小型更新，但都是一些重要的错误修复!
错误修复
● 通用
 ○ 修复了装备再生护甲的玩家受到特定类型的伤害时，即使伤害本应是致命的，仍会剩下1点生命值的问题。
 ■ 这项改动同时也修复了再生护甲和虹吸同时激活时，暮蝶能够承受致命伤害的问题。
● 英雄
 ○ 维斯
 ■ 修复了弧光玫瑰和剃刀藤蔓置于特定水面上时可见的问题。
 ○ 钛狐
 ■ 修复了玩家在极少数情况下能够在末日审判的整个持续时间内径直穿过攻击范围并存活下来的问题。
 ○ 奇乐
 ■ 修复了奇乐的召回小地图指示器可能会陷入不可见状态的问题。
 ■ 自动哨兵的逻辑已更新，变得更加智能。
 ● 在特殊情况下，如果玩家位于边缘区域，自动哨兵会直接朝玩家的方向移动，并在爆炸范围能命中玩家时直接引爆，而不是在地图上绕远路去接近玩家。
● 玩法系统
 ○ 修复了观看者看到的玩家队伍轮廓颜色不一致的问题。
 
感谢您对《无畏契约》的支持和帮助!
