# v7.12版本

> **日期**：2023-12-07 ｜ **类型**：小版本
> **公告时间**：2023-12-06 18:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 12月7日3:00进行不停机版本更新，更新过程中各位玩家可以在游戏内进行正常体验，更新过程中可能会出现短暂匹配异常或服务波动等情况，为各位玩家带来的不便我们深表抱歉。
第七季(同时也是2023年)的最后一个版本更新来了!大家可要抓紧时间了，趁新一年的重置还未到来，赶快完成战斗通行证和多多提升段位吧!
本次v7.12版本更新内容如下：
英雄更新
盖可
盖可的特长之一，就是能回收自己的小怪兽。这一改动旨在加快回收过程，让玩家可以在更多情况下进行回收。此外，我们还提升了炫晕光波(E)的可靠性，以增加盖可使用这一技能的信心，同时鼓励他积极进行回收。
 ● 回收炫晕光波(E)、顽皮搭档(Q)、无敌超鲨(X)
 ○ 回收引导时间从2秒减少至1秒
 ● 炫晕光波(E)
 ○ 丢丢准备就绪并且看到目标后，将更快发射电浆冲击，投射物的飞行速度也会更快。
 ○ 发射前摇从0.5秒降低至0.35秒
 ○ 投射物速度从7000提升至10000
斯凯
这些改动的重点在于鼓励斯凯在使用辟林之虎(Q)时多加思考：
 ● 辟林之虎在飞扑时无法再调整镜头，所以斯凯现在需要考虑得更加周全，在&ldquo;进行飞扑、移动更远距离&rdquo;和&ldquo;放弃飞扑、观察更多角度&rdquo;这二者之间做出抉择。
 ● 从现在开始，若敌人趁辟林之虎飞扑的间隙成功将其摧毁，就能取消其震荡效果，从中获益。
 ● 取消震荡效果的敌友之分，使它与其它技能保持一致(如盖可的无敌超鲨)。斯凯和队友若想要成功利用辟林之虎，就需要多加协调与权衡。
 ● 辟林之虎(Q)
 ○ 飞扑期间无法控制镜头移动。
 ○ 若辟林之虎在飞扑途中被摧毁，将不再造成震荡冲击。
 ■ 若辟林之虎在飞扑途中被摧毁，将播放摧毁语音。
 ○ 辟林之虎的爆炸将震荡敌友双方。
地图更新
 ● 团队乱斗即将迎来全新地图&mdash;&mdash;渔市!这张地图中路长，侧路偏，换路方式也非常刺激!
游戏功能更新
 ● 原始输入缓冲
 ○ 移除&ldquo;测试&rdquo;标签
 ○ 默认值由关改为开
 ■ 已有的设置值不受影响
错误修复
 ● 英雄
 ○ 修复了控制某些技能时，达成击败无法得到奖励的问题。受影响的技能包括：猎枭控制枭型无人机(C)时用雷击箭(Q)达成击败、盖可控制无敌超鲨(X)时用嗨爆全场(C)达成击败、零控制战术监控(E)时用震慑绊线(C)达成击败。
 ○ 若K/O在使用无效命令(X)期间被击败，将向游戏内所有人显示红色头像。
 ● 玩家行为
 ○ 修复了罕见情况下，被检测到挂机的玩家会在下一回合重生，导致队友得不到手枪局奖励的问题。
 
商城更新
12月7日 ，机动狂飙套装将上架游戏商城!套装由机动狂飙 战刀、机动狂飙 狂徒、机动狂飙 雄鹿、机动狂飙 蜂刺、机动狂飙 正义、机动狂飙 喷漆、机动狂飙 卡面、机动狂飙 挂饰等八件道具组成。
