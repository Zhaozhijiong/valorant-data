# v9.09版本

> **日期**：2024-11-07 ｜ **类型**：小版本
> **公告时间**：2024-11-06 12:12:45

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 11月7日 8:00进行不停机版本更新，更新过程中大家可以在游戏内正常进行对局，若有偶现的匹配不可用请稍作等待即可恢复，为您带来的不便我们深表抱歉。
本次v9.09版本更新内容如下：
错误修复
通用
● 修复了&ldquo;英雄选择&rdquo;的锁定动画在秒选时不会立即播放的错误。
● 修复了玩家作为锦标赛教练在&ldquo;英雄选择&rdquo;期间会看到空白屏幕的错误。
● 修复了在&ldquo;找到比赛&rdquo;弹窗出现时，玩家可以离开房间提前进入&ldquo;英雄选择&rdquo;界面的错误。
 
英雄
● 修复了夜露在使用神鬼不觉后，夜露无法正确握持夜刃诡镰的问题。
● 修复了盖可的鲨鲨很难进行小幅跳跃的错误。现在，鲨鲨的跳跃方式应该会更接近玩家。
● 修复了被钢锁的断魂索道拖拽的玩家有时会卡在边缘顶部的错误。
● 修复了玩家在遭到黑梦的黯兽噬咬期间可以把它甩掉的错误。现在，黯兽在噬咬期间应该会持续追踪目标，除非目标传送至其视线之外。
● 修复了当星礈被零的战术监控监视时，无法收到警报音效的错误。
● 修复了奇乐的哨戒炮台在和其它技能或武器来回切换后，无法在小地图上显示无效范围的错误。
● 修复了激活无效命令的K/O可以被施放神鬼不觉的夜露进行重启的错误。
 
地图
● 幽邃地窟
○ 修复了从特定角度射击时，中区的可破坏门会被摧毁的错误。
 
感谢您对《无畏契约》的支持和帮助!
