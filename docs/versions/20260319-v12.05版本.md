# v12.05版本

> **日期**：2026-03-19 ｜ **类型**：小版本
> **公告时间**：2026-03-18 10:43:19

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 3月19日1:00~5:00 进行停机版本更新，2026赛季第一幕竞技模式将于 3月18日 22:00 正式结束，停机更新结束后将进入2026赛季第二幕新赛季，竞技模式段位将进行重置。此外，2026赛季第一幕战斗通行证也将在停机更新开启时正式结束。
想要了解更多这个版本的精彩内容，可以从这里前往我们的2026赛季第二幕专题页!
 
随着第二幕开启，今天我们有很多精彩内容分享，包括来自欧洲中南部的无畏契约新英雄&mdash;&mdash;迷核!
 
此外，游戏平衡团队为部分改动补充了一些背景说明，如果你想了解开发者的一手讯息，那就不要错过斜体字的部分哦!以下是即将更新的内容：
内容概述
●欢迎新英雄-迷核!向无畏契约最新控场打个招呼吧~
●全新限时模式夺还模式上线。爆能大乱斗模式即将下线。
●贤者选定目标队友的界面设计和交互体验已更新，与迷核的选定体验保持一致。
●贤者也迎来了模型更新，以契合她在无畏契约背景故事中的最新形态。
●夜露、暮蝶和斯凯迎来平衡性调整。铁臂获得新增语音。
●竞技模式地图池已更新，对莲华古城A区进行了部分调整。
●助攻提示已加入状态栏，你的每一次助攻都值得庆祝。
●击败信息也已更新，击败助攻和技能助攻的显示更加清晰。
●状态栏上的效果标签已更新，更加清晰明了。
 
在12.05版本中，我们将重点关注团队协作和英雄选择的多样性。我们认为，个人的枪法和操作确实能够展现出真正的实力，但团队协作、利用英雄协同作战，依然是执行策略的最佳方式。
因此，这次英雄更新旨在稍微削弱几位&ldquo;以自我为中心"、&ldquo;个人能力过强&rdquo;的英雄(比如暮蝶和夜露)。另外，随着迷核加入小队，最强搭档也有了新的人选。嗯......顽皮搭档可不参与评选。
我们还对击败信息的显示进行了部分体验升级，更新后会清晰地显示技能助攻以及参与击败的英雄，同时在屏幕下方增加助攻提示，让你更容易判断自己是否获得了助攻。同时我们优化了贤者【逢春】和迷核【共振谐律】等技能选定目标队友的体验。这些都是为了表彰和激励优秀的团队协作。
 
英雄更新
●新英雄-迷核
来自欧洲中南部的&ldquo;迷核&rdquo;能够操控纯粹的声波能量。凭借极具感染力的激情和独特的音波力量，他率领全队协同作战，定下战场的主导节奏。
 ○技能：
 ■电音脉冲
 ●装备电音脉冲。按【辅助射击】可在震荡输出与治疗输出之间切换。按【射击】投掷装置。落地时，电音脉冲会释放声波，对玩家造成震荡或治疗效果。
 ■共振谐律
 ●装备共振谐律。锁定一名队友并按下【射击】，为你和该队友激活【作战强化】效果，每次击败敌人都会刷新效果。按【辅助射击】让自己获得【作战强化】效果。
 ■声波帷幕
 ●装备地图定位仪。按【射击】设定位置。按【辅助射击】在选定位置释放烟雾。
 ■音脉强袭
 ●装备音脉强袭。按【射击】积蓄能量并向前释放音波源光，击退目标，并对其造成【致聋】和【减速】。

自从去年年底调整了先锋英雄的技能冷却时间后，我们开始重新评估移除【引路之隼】充能的决定。冷却时间设置在45秒，意味着斯凯开局就能用该技能进行随意侦查，而且几乎没有代价;而我们希望她在使用该技能时更加有意识、更为慎重。如果将冷却设置为60秒，这种取舍就会变得更加明显。

夜露正在挤压具备闪光能力的先锋英雄的生存空间，甚至连哨卫也受到了影响，在高分段和职业比赛中尤其明显。他拥有阵容中最强的转点能力，能够非常出色地向前推进，并且拥有游戏中适用性最广的闪光技能之一。总体来说，我们认为夜露现在过于强势，已经影响了其他位置，破坏了阵容选择的多样性。因此，我们将调整他最强的两个技能：【不请自来】和【攻其不备】，让夜露在使用它们时需要做出更有意义的取舍。
●夜露
 ○不请自来
 ■锚点持续时间从30秒减少至15秒
 ○攻其不备
 ■充能次数由2次减少至 1次
 
自上线以来，暮蝶一直是排位赛中的常青选择，胜率也远高于其他英雄。我们希望，对其进行的强度调整和新英雄迷核的加入能为控场位带来更多选择。
由于暮蝶在阵亡后依然能极大助力队伍取胜，我们针对这一现状做出了调整。

模式更新

 ■模式详情

 ○击败一名敌人即可复活一名队友

 ■进入敌方领地后，小地图会变得模糊，让你难以掌握敌人位置

 ○率先赢得4回合的队伍获胜
