# v12.07版本

> **日期**：2026-04-16 ｜ **类型**：小版本
> **公告时间**：2026-04-15 14:13:31

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 4月16日 5:00 进行不停机版本更新，更新过程中大家可以在游戏内正常进行对局，个别网吧由于使用较老的网盘更新方案，可能存在更新版本时偶发掉线的问题，为您带来的不便我们深表抱歉。
本次v12.07版本更新内容如下：
常规更新
● 设置界面现已全面更新，功能更强大，视觉更清晰
 ○ 为存在关联的设置新增上下级关联
 ○ 新增悬停提示
 ○ 原先位于&ldquo;通用-其他&rdquo;的设置现已拆分为三个板块：用户界面、内容过滤、网络
 ○ 视觉效果更新
● 我们知道有些玩家会在游戏过程中快速调整设置，也无意干扰这类玩家的设置体验。经过调整的整体体验会与之前大致保持相同，但品质将有所提升。
 
错误修复
● 外观物品
○ 我们对多款瞄准镜的准星进行了更新，使其中心视野范围与基础瞄准镜准星更加一致。获得本次更新的皮肤有：塑水宗 飞将、黯夜怪谈 飞将、创&middot;纪元 莽侠、归零者//2.0 莽侠和归零者 冥驹。
 
● 商城
 ○ &ldquo;不符合赠礼资格&rdquo;界面现已扩展至全屏宽度。
 ○ 修复了枪械挂饰购买确认中出现的多处穿模问题。
 ○ 修复了购买确认界面标题文字的显示颜色问题。
 ○ 修复了礼包详情按钮的多处不一致问题。
 ○ 修复了购买流程中预览喷漆时显示变暗的问题。
 ○ 统一了购买流程各个环节中的礼包展示高度。
 ○ 已拥有某个礼包时，其图标将不会在推荐礼包图块中显示。
 ○ 修复了赠送盘盘时优惠图块变色的问题。
 ○ 修复了好友列表较长时导致轻微卡顿的问题。
 
感谢您对《无畏契约》的支持和帮助!
