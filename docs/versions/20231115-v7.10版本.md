# v7.10版本

> **日期**：2023-11-15 ｜ **类型**：小版本
> **公告时间**：2023-11-14 18:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 11月15日8:00进行不停机版本更新，更新过程中各位玩家可以在游戏内进行正常体验，更新过程中可能会出现短暂匹配异常或服务波动等情况，为各位玩家带来的不便我们深表抱歉。
本次v7.10版本更新内容如下：
 
常规更新
● 为了减少对局的加载时间、帮助硬件配置较低的玩家获得更好的体验，我们调整了调取玩家装备的方式。
 
英雄更新
钢锁
从现在开始，任何被重力捕网(C)捕获的目标，都必须手动移除捕网，才能摆脱效果的影响。在此之前，被捕获的目标只需要离开捕网的覆盖范围，或是等待技能效果失效，就能移除捕网。我们认为这一调整可以开发出独特的优劣势，同时让双方的互动更加有趣&mdash;&mdash;要解除减益效果，敌人就不得不放下手中武器、弄出声响。另外，为了提升此技能的可靠性，同时避免像捷风和雷兹这样高机动性的英雄轻而易举逃过捕网的抓捕，我们增加了此技能的影响范围。
 
● 被重力捕网捕获的目标将受到减益效果，持续至捕网被移除为止。
● 被重力捕网捕获的目标将受到更大的重力影响，机动性也会受限(例：重力捕网将减少捷风使用逐风(E)时的移动距离)
● 重力捕网移除时间从0.85秒增加至1.5秒
● 重力捕网范围从6米增加至8米
 
捷风
● 我们调整了捷风装备飓刃丛飞(X)时的第三人称动画，以提升战斗的清晰度。现在她奔跑和投掷飞刀的动作应该会更加清楚可见。
 
团队乱斗模式限定改动
芮娜
○ 团队乱斗空间狭窄，芮娜的睥睨(C)不会对队友造成影响，在这里就有了更大的发挥空间。此外，只要芮娜不停歼灭敌人，就能不受时间限制地使用女皇旨令(X)，使她变得势不可挡。以下调整旨在创造更多空隙，降低这些强大技能的使用频率。同时，如果芮娜想利用女皇旨令掌握局势，就必须更专注于收集能量球。
■ 仅限于团队乱斗的调整：
● 睥睨(C)的冷却时间从44秒增加到51秒
● 女皇旨令(X)的充能速度将降低14%
 
黑梦
○ 在团队乱斗中，黑梦的技能使用难度会比较大，发挥的空间也不多。以下调整旨在帮助她追踪并接近敌人。
■ 仅限于团队乱斗的调整：
● 黯兽(C)的冷却时间从44秒减少至36秒
● 幽爪(Q)的冷却时间从51秒减少至48秒
 
游戏功能更新
● 数据页面添加了预设
 
错误修复
● 通用
○ 修复了混响效果无法在部分类型的声音上(包括枪声和脚步声)正常应用的问题。
○ 修复了蝰腹(X)有时无法在小地图和大地图上正确封锁敌方视线的问题。
○ 修复了黑梦的黯兽(C)可以穿过某些物体的问题。
 
● 玩家行为
○ 修复了&ldquo;举报玩家&rdquo;菜单上，阿拉伯语举报按钮的文本被截断的问题。
 
感谢您对《无畏契约》的支持和帮助!
