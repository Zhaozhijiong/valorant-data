# v10.03版本

> **日期**：2025-02-21 ｜ **类型**：小版本
> **公告时间**：2025-02-20 12:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 2月21日 5:00 进行不停机版本更新，更新过程中大家可以在游戏内正常进行对局，若有偶现的匹配不可用请稍作等待即可恢复，为您带来的不便我们深表抱歉。
本次v10.03版本更新内容如下：
大家好，《无畏契约》曼谷大师赛近在眼前，因此本周推出的依旧是一次小型改动。本次更新带来了小地图的清晰度优化，尚勃勒、斯凯和海神的减速效果调整，以及若干错误修复。
祝大家玩的开心!
英雄更新
● 现在，所有英雄的减速技能都会统一减缓冲刺，以匹配9.10和9.11版本对维斯以及震荡效果的调整。
 ○ 这意味着尚勃勒、斯凯和海神的减速技能现也将受到影响。
玩法系统更新
● 已优化小地图的视觉语言，以提高游戏清晰度和视觉质量。

错误修复
● 通用
 ○ 修复了爆炸伤害型技能可以从远超其设定范围的距离摧毁哨卫陷阱技能(如维斯的弧光玫瑰)的问题。
 ○ 注意：为了调查和修复该问题，10.01/10.02版本曾暂时关闭了新的爆炸伤害机制。我们将持续监控这些调整，确保没有其它需要停用机制的情况。
● 玩法系统
 ○ 修复了重赛投票界面出现时，玩家无法移动或使用购买菜单的问题。新的投票部件还优化了颜色显示：现在，&ldquo;确认&rdquo;按钮为绿色，&ldquo;拒绝&rdquo;按钮为红色。
 
感谢您对《无畏契约》的支持和帮助!
