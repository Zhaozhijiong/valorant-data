# v10.07版本

> **日期**：2025-04-17 ｜ **类型**：小版本
> **公告时间**：2025-04-16 12:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 4月17日 8:00 进行不停机版本更新，更新过程中大家可以在游戏内正常进行对局，若有偶现的匹配不可用请稍作等待即可恢复，为您带来的不便我们深表抱歉。
本次v10.07版本更新内容如下：
错误修复
● 英雄
 ○ 芮娜
 ■ 修复了芮娜的终极技能视觉效果可透过视野收缩效果显示的问题。
 ○ 幻棱
 ■ 修复了幻棱若在收取能量球时激活溯流回光，无法正确传送返回的问题。
 ■ 修复了幻棱可以在幽邃地窟的可游玩空间外激活溯流回光的问题。
 ■ 修复了幻棱若位于传送点正上方时触发溯流回光的回溯，会抬头直视天空的问题。
 ○ K/O
 ■ 修复了K/O若在施放无效命令期间被队友复活，即使在过程中被击败，其复活音效仍会持续播放的问题。
 ○ 维斯
 ■ 修复了维斯的墙体若在特定时间与烟雾技能重叠，可能会导致敌人卡在其墙内的问题。
 ■ 修复了敌人若在维斯的裁断触发时跳跃，可能被卡在其中的问题。
 ■ 修复了敌人离开裁断的技能范围或维斯阵亡时，裁断的音效会持续对敌人播放的问题。
 ○ 暮蝶
 ■ 修复了暮蝶使用霞染装备战场地图时，其他玩家能从高地下方看到战场地图的问题。(这个问题有点难解释，大家请直接看图吧!)
 ■ 修复了暮蝶的虹吸持续时间在观看者/观众视角无法正确显示的问题。
 ○ 零
 ■ 修复了敌人在被震慑绊线命中后传送离开，再次穿过同一条重新激活的绊线时不会受到束缚的问题。
 ○ 钛狐
 ■ 修复了末日审判的地面指示器会在各个回合中持续存在的问题。
 ○ 幽影
 ■ 修复了幽影施放黑瘴时，若与另一种浓厚烟雾(遮挡内部视野的烟雾，如捷风的瞬云、炼狱的空投烟幕等)重叠，会导致他视野受阻的问题。
 ○ 钢锁
 ■ 修复了钢锁的网状技能视觉效果可透过薄墙显示的问题。
 ○ 猎枭
 ■ 修复了英雄选择界面中，猎枭的手臂和无人机相互重叠的问题。
 ○ 尚勃勒
 ■ 修复了视野收缩时，可能会看到尚勃勒的手表和眼镜的问题。
● 通用
 ○ 修复了神中神罚系列武器皮肤有时会发出强烈光芒，可能引发光敏反应的问题。
● 竞技模式更新
 ○ 修复了比赛记录和结算界面中，若玩家已经耗尽段位保护，段位保护图标上的悬停文本会丢失的问题。
 
感谢您对《无畏契约》的支持和帮助!
