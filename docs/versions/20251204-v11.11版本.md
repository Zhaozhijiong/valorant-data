# v11.11版本

> **日期**：2025-12-04 ｜ **类型**：小版本
> **公告时间**：2025-12-03 11:36:10

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 12月4日 8:00 进行不停机版本更新，更新过程中大家可以在游戏内正常进行对局，个别网吧由于使用较老的网盘更新方案，可能存在更新版本时偶发掉线的问题，为您带来的不便我们深表抱歉。
本次v11.11版本更新内容如下：
系统更新
●英雄页面UI更新
 ○英雄页面已更新为以网格形式展示完整的英雄阵容。你可以使用鼠标或方向键浏览每位英雄。和之前差不多，但更好一些&mdash;&mdash;正因为这点不一样，所以更好一些。
错误修复
●英雄
 ○尚勃勒：
 ■修复了闪转自如的音效会在传送动画末尾突然结束的错误。
 ○暮蝶：
 ■修复了在暮蝶使用化蝶后立刻将其击杀时，会导致某些终结特效表现异常的错误。
 ■修复了当暮蝶在使用化蝶后在烟雾中被击败时，其在队伍顶部栏的英雄图标无法正常更新的错误。
 ■修复了被击败的暮蝶上方有太多玩家站立时，暮蝶复活时会出现在出生点并拥有化蝶的错误。
 ■修复了暮蝶的虹吸过量治疗界面效果在过量治疗降至0后仍会停留在HUD界面上的错误。
 ○零：
 ■修复了敌方玩家隐藏在零的赛博囚笼时，其位置仍可能会在小地图上短暂暴露的错误。
 ■修复了摄像头在回收过程中被摧毁，会导致零的战术监控看似已被成功回收的错误。
 ■修复了如果零在完成布置震慑绊线前被击败，会导致震慑绊线视觉上仍显示为已激活的错误。
 ○捷风：
 ■修复了捷风可能会在平台或箱子边缘附近卡在半空中的错误。
 ○海神：
 ■修复了海神的乱涌会在神鬼不觉期间影响夜露的错误。
 ■修复了海神的乱涌击中被击败的暮蝶时，玩家会看到视野收缩界面效果的错误。
 ■修复了海神的海盾在上下检视时会突然旋转180度的错误。
 ■修复了海神的怒涛小地图标记会短暂残留并阻挡锥形视野区域的错误。
 ■修复了海神的乱涌和怒涛在旁观者将视角切换到刚被技能击中过的玩家时，会显示彩色方块的错误。
 ○壹决：
 ■修复了暮蝶与芮娜在以过量治疗受损状态进入壹决的决斗通牒时，无法以满生命值和满护盾或过量治疗进入的错误。
 ■修复了当不死鸟处于再火一回状态并离开壹决的决斗通牒后，其原本的生命值与护甲不会恢复的错误。
 ○不死鸟：
 ■修复了不死鸟的火热手感在战斗报告中显示治疗量不准确的错误。
 ○芮娜：
 ■修复了即使芮娜没有技能充能，噬尽和逐散提示图标仍会残留在界面上的错误。
 ■修复了旁观者视角下芮娜的过量治疗生命值在界面显示不准确的错误。
 ○斯凯：
 ■修复了斯凯的愈生之息会治疗某些可部署装置的错误。
 ○钛狐：
 ■修复了钛狐的潜袭爬虫会推开玩家并给予速度加成的错误。
 ○禁灭：
 ■修复了禁灭的涡流折跃有时可以穿透不可射穿墙体的错误。
 ○维斯：
 ■修复了猎枭的寻敌箭与K/O的零点嗅探会被激活的裁断墙体困住，而不是被摧毁的错误。
●地图
 ○隐世修所
 ■修复了A点附近的A区小道中，某个点位穿墙判定存在错误的问题。
已知问题
●V25第三幕排位专属挂饰将暂时在你的收藏中错误显示为&ldquo;V25第六幕&rdquo;。
 ○别担心!你在2025赛季前三幕获得的挂饰不会受到影响。
 ○名称将在12.00版本中恢复正常，你也会正常收到自己的V25第六幕挂饰(如果你在2025赛季最近三幕中获得了赛幕段位)。
感谢您对《无畏契约》的支持和帮助!
