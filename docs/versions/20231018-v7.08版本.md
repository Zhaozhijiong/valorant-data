# v7.08版本

> **日期**：2023-10-18 ｜ **类型**：小版本
> **公告时间**：2023-10-17 18:03:42

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在10月18日5:00进行不停机版本更新，更新过程中各位玩家可以在游戏内进行正常体验，更新过程中可能会出现短暂匹配异常或服务波动等情况，为各位玩家带来的不便我们深表抱歉。
本次v7.08版本更新内容如下：
常规更新
 ● 为了给未来的英雄腾出空间，我们对英雄选择界面下方的英雄栏位进行了小小的视觉调整。
英雄更新
 ● 烟雾视觉特效更新
 ○ 一些关键的烟雾技能可以在相当长的一段时间内切割作战空间，我们认为，应该让玩家能够准确把握这段时间、并依此做出合理决策。因此，我们对一些持续时间较长的烟雾技能进行了调整：在它们的效果结束前添加了视听提示，以提前告知玩家烟雾即将消失。
 ■ 烟雾会在即将消散前的1.5秒播放视听提示。烟雾技能受到影响的英雄为：
 ● 星礈
 ● 炼狱
 ● 幽影
 ● 队友不再能听到你装备技能的音效。
 ○ 之前，当你使用特定英雄时，离你非常近的队友可以听到你装备技能的声音。队友听不到装备枪支的声音，却听得到装备技能的声音，这种矛盾引发了玩家的困惑，不确定敌人是否也能听到这些声音。我们希望这项调整可以统一枪支和技能装备的音效规则，让玩家更容易知道敌人究竟可以听到什么声音。
商店更新
 ● 我们更新了等级边框和玩家卡面的收藏界面!从现在开始，你可以在网格布局的界面中搜索、浏览和装备你的等级边框和玩家卡面。
错误修复
英雄
 ● 钢锁
 ○ 断魂索道(X)无法再从传送室外打开源工重镇的自动门。
 ○ 断魂索道(X)无法再从下方打开微风岛屿中区滑道的活板门。
 ● 霓虹
 ○ 从室外施放时，高速通道(C)现在可以更可靠地完整穿过裂变峡谷的A区门，从而与从A区大堂内施放时的表现一致。
通用
 ● 修复了载入地图或靶场时，音乐会出现停顿/间断的问题。
 ● 修复了一个导致靶场机器人重生时，无法正确重置命中判定框(hitbox)位置的问题。
玩家行为
 ● 修复了一个错误，以确保涉及违规行为的玩家受到正确的段位评分惩处。
武器
 ● 修复了击败旗帜出现时，音效音量过小的问题。
