# v8.02版本

> **日期**：2024-02-07 ｜ **类型**：小版本
> **公告时间**：2024-02-06 21:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 2月7日8:00进行不停机版本更新，更新过程中各位玩家可以在游戏内进行正常体验，更新过程中可能会出现短暂匹配异常或服务波动等情况，为各位玩家带来的不便我们深表抱歉。
本次v8.02版本更新内容如下：
英雄更新
蝰蛇
● 蝰蛇的瘴云(Q)手雷获得了美术更新。
其它改动
● 对腐坏减益的视觉效果进行了更新，使其变得更加清晰和易于辨识。
物品外观更新
● 蛇吻短炮获得了美术更新。
 
活动更新
祥龙呈瑞活动通行证上线!
为庆祝春节到来，在2月7日到2月28日期间，我们将会开放祥龙呈瑞活动通行证，在此期间通过累计经验能够获取共6级奖励，让我们一同欢庆新年!
● 1级奖励：好运福爪 挂饰
● 2级奖励：10点源晶点数
● 3级奖励：恭喜发财 称号
● 4级奖励：醒狮贺春 喷漆
● 5级奖励：10点源晶点数
● 6级奖励：龍记 卡面
错误修复 
玩法系统
● 修复了使用范围效果技能击败多个敌人时，击败通知数字显示不正确的问题。
● 修复了&ldquo;自动重新开镜&rdquo;设置无法正确更新的问题。
玩家行为
● 修复了行为信息系统中额外显示无关细节的问题。
 
赛事中心
原计划于8.02版本上线的赛事中心，将承载2024无畏契约冠军巡回赛(VCT)完整赛制和赛区赛程信息，但由于CN赛区部分与游戏客户端联通的数据尚未完成处理，功能将延后到3月初v8.04版本中再与国服玩家见面。此外，大家也不用担心在此期间无法关注到VCT赛事：2月22日-3月2日期间所有VCT CN启点赛，我们依然会在官网电竞专区以及官方登录器电竞版块全程提供赛事赛程信息和直播。
感谢您对《无畏契约》的支持和帮助!在此提前祝大家新年快乐!
