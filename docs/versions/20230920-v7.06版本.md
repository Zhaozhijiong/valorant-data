# v7.06版本

> **日期**：2023-09-20 ｜ **类型**：小版本
> **公告时间**：2023-09-19 18:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在9月20日 5:00进行不停机版本更新，更新过程中各位玩家可以在游戏内进行正常体验，更新过程中可能会出现短暂匹配异常或服务波动等情况，为各位玩家带来的不便我们深表抱歉。
 
本次v7.06版本更新内容如下：
英雄更新
贤者
● 我们更新了贤者的语音，并丰富了她与其他英雄的互动台词。
竞技模式更新
● 目前，游戏中出现了少量以不正当的方式组队上分的情况。为了制止这种现象，我们实行了一些限制：超凡或以上段位的玩家仅能与铂金或以上段位的玩家进行排位匹配。
● 我们将继续积极监控自动脚本滥用行为，对一切可疑账号进行封禁。
● 想了解更多有关玩法系统，以及我们消除违规行为具体做法的信息可以点此查看>>
 
玩法系统更新
● 我们对战斗记录进行了一些后端更新，以修复正确信息无法显示的问题。如果出现任何异常状况(尤其是在输掉比赛后或回合开始前)，请告知我们。
错误修复
玩法系统
● 修复了购买武器后，玩家会无意间被揭露、出现在错误位置的偶现问题。
● 修复了爆能器部署和拆除界面栏无法对简化版HUD观看者显示的问题。
● 修复了日落之城的回合开始前，视野范围会闪烁的问题。
 
商城更新
晶态集成套装在9月21日正式上架主打商店!
礼包售价：2360无畏点券
包含内容：晶态集成 冥驹，晶态集成 戍卫，晶态集成 骇灵，晶态集成 标配，硅晶刻刀
售卖时间：2023/9/21 5:00 至 2023/10/05 5:00

 
感谢您对《无畏契约》的支持和帮助!祝大家玩得开心!
