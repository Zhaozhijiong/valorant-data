# 第九季第一幕新竞技地图"幽邃地窟"上线

> **日期**：2024-06-28 ｜ **类型**：大版本
> **公告时间**：2024-06-26 21:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 6月28日1:00~5:00 进行停机版本更新，第八季第三幕竞技模式将于 6月27日 22:00 正式结束，停机更新结束后将进入第九季第一幕新赛季，竞技模式段位将进行重置。此外，第八季第三幕战斗通行证也将在停机更新开启时正式结束。
本次v9.00版本更新内容如下：
英雄更新
● 我们新增了英雄之间的对话语音，其中包括不死鸟、海神、炼狱、夜露、雷兹、壹决、贤者、霓虹、盖可、斯凯、钢锁、幽影、K/O，以及芮娜。
壹决
壹决最近在率先进点时变得更有自信了，这是一件好事。但我们希望，让他在激活战斗心流时更加谨慎。这样一来，无论是击破他的护盾，还是毁掉他的战斗心流能量球，这些反制手段应该都能发挥更大的作用。
因此，我们减少了战斗心流增益的持续时间，同时也移除了完成两次击败后获得的重置效果。从现在开始，壹决只能在增益效果的生效时间内，通过射击生成的能量球延长战斗心流的持续时间。
● 战斗心流(E)：持续时间从20秒减少至12秒
 ○ 移除了招牌的击败重置效果
竞技模式更新
● 幽邃地窟加入竞技模式地图池。
玩家行为更新
● 除了从文字聊天中移除禁用词外，我们也将对屡次进行这种违规行为的玩家施以更严厉的惩罚。
社交更新
● 添加好友时，你现在可在&ldquo;游戏昵称&rdquo;的信息栏中粘贴或输入完整的游戏昵称(包括标签)，系统会自动将数据拆分到&ldquo;游戏昵称&rdquo;和&ldquo;标签&rdquo;信息栏中。
错误修复
玩法系统
● 所有平台
 ○ 修复了使用等级3、等级4的千灵华绽系列皮肤时，开镜时出现粒子效果错误的问题。
 ○ 修复了退出零的战术监控(E)后，零的手在观众视角发生卡顿的问题。
地图
● 幽邃地窟
 ○ 修复了几个有违设计意图的跳点。
 ○ 修复了允许玩家进入地图下方的错误。
 ○ 现在，A区的掩体将可以在幽影和星礈的烟雾投放区域内正确显示。
 ○ 修复了一个可以让幽影进入重生点屏障之间的错误。
已知问题
● &ldquo;艾沃莉的梦之翼 星梦吊坠&rdquo;在对局内颜色不会随炫彩变化而是保持默认颜色，该问题会在后续版本修复
 
感谢您对《无畏契约》的支持和帮助!
