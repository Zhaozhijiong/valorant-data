# v9.03版本

> **日期**：2024-08-15 ｜ **类型**：小版本
> **公告时间**：2024-08-14 21:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 8月15日 8:00进行不停机版本更新，更新过程中大家可以在游戏内正常进行对局，若有偶现的匹配不可用请稍作等待即可恢复，为您带来的不便我们深表抱歉。

本次v9.03版本更新内容如下：
常规更新
● 改进了物品重叠时的交互逻辑。现在，玩家应该可以更一致地执行所需操作了。
 ○ 举例：正面对着绳索时，来自零战术监控(E) 的飞镖(按F键拔除)将无法再阻止玩家附着到绳索(按F键连接/分离)上。
英雄更新
● 地面扩散技能
 ○ 我们正在对沿地面扩散的技能进行改进，如炼狱的燃烧榴弹(Q)和蝰蛇的蛇吻(C)等。在此之前，这些技能会随着着地具体位置的不同，产生不一致的效果：有的是效果范围产生巨大差异，有的效果则会穿过墙壁，或在视觉效果不存在的区域造成伤害。这次更新后，这些技能的扩散效果应该会更加一致，且只会在视觉效果可见的位置造成伤害。
● 地图定位技能改进
 ○ 玩家现在可以在地图上标记位置，也会看到更多用于定位技能的图标
■ 受影响的技能：炼狱的空投烟幕(E)和天基光束(X)、暮蝶的霞染(E)，以及幽影的离魂(X)
● 贤者的玉城
 ○ 玉城(C)的放置预览现在也会显示在小地图上
游戏性能更新
● 改进了壹决决斗通牒(X)的性能表现。
错误修复
通用
● 修复了打开菜单会重置&ldquo;切换蹲伏/切换步行&rdquo;状态的问题。
玩法系统
● 修复了在回合开始前，需要同时按住[Tab]键并按下光标切换按钮才能启用光标的问题。
● 修复了点击地面上的枪械发送信号时，文字信息中不会显示枪械名称的问题。
● 修复了回合计时器归零的同时拆除爆能器，拆除计时器会显示&lsquo;-00.00&rsquo;的罕见问题。
● 修复了作为观看者观看对局时，技能图标不会在小地图上显示的问题。
● 修复了在特定场景中，玩家可以看到敌人，敌人却不会在小地图上显示的问题。
● 修复了&ldquo;对你造成/你造成的伤害&rdquo;与&ldquo;战斗记录&rdquo;部件重叠的问题。
● 修复了某些语言中战斗记录字体大小的可读性问题。
● 修复了莽侠、飞将和冥驹的自动重新瞄准功能在换弹时仍处于激活状态的问题。
地图
● 幽邃地窟
 ○ 修复了投掷技能会在中区图书馆的特定位置穿过书架进入游戏空间的问题。
 ○ 修复了英雄技能可以被投掷到地图外并用作平台的问题。
 ○ 修改了沙漏之子的信息，以修复文本错误的问题。
 ○ 修复了守方重生点周围栏杆的视觉效果问题。
感谢您对《无畏契约》的支持和帮助!
