# v7.00e版本

> **日期**：2023-08-10 ｜ **类型**：小版本
> **公告时间**：2023-08-09 18:34:19

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在8月10日 4:00进行不停机版本更新，更新过程中各位玩家可以在游戏内进行正常体验，更新过程中可能会出现短暂匹配异常或服务波动等情况。
本次更新需要游戏安装磁盘预留3G以上的可用空间，C盘预留10G以上的可用空间用作缓存文件加载(更新完成后缓存文件会自动删除，不会继续占用内存)，为各位玩家带来的不便我们深表抱歉。
 
本次更新内容如下：
 
商店更新
 
《奇点》系列礼包将在8月10日正式上架主打商店
礼包售价：6360无畏点券
包含内容：幻影、骇灵、正义、战神、军刀、喷漆、卡面、挂饰
售卖时间：2023/8/10 05:00 至 2023/8/24 05:00

 
玩家行为系统更新
 ● 受到队伍文字聊天禁言的用户，将同时受到房间文字聊天禁言。
 ● 为了提高可视性和可读性，我们修改了行为警告信息系统的格式。
 
收藏系统更新
购买和对局结束解锁后添加收藏
 ● 对局结束后，若玩家购买或解锁了战斗通行证或活动通行证物品，可在确认界面上立即收藏新购买/解锁的武器或饰品(不包括称号)。
进入喷漆收藏页面
 ● 对局结束后，若玩家购买或解锁了战斗通行证或活动通行证喷漆，可从确认界面直接跳转到&ldquo;收藏&rdquo;标签，查看新获得的喷漆。
 
错误修复
 ● 修复了使用终极技能时，玩家头像上会出现一条白线的问题。
 ● 修复了护盾受到损伤后，在商店中再次购买时，护盾值会以红色显示的问题。
 ● 修复了VOIP减弱非战斗语音(一种打开后会稍微降低游戏内声音，使房间/队伍通讯更清晰的设置)无法正常运行的问题。
 ● 修复了网吧特权免费皮肤未在特权面板中进行文案展示的问题。
 
2023全球冠军赛火热进行中
 ● 北京时间 8 月 7 日 - 27 日，来自全球的16支顶级强队齐聚洛杉矶，争夺全球冠军赛奖杯和无畏契约世界冠军的称号!
 ● 赛事期间直播观赛或是游戏内组队开黑，均可获得VCT主题限定卡面/喷漆及称号，点击链接了解详情
感谢您对《无畏契约》的支持和帮助!
