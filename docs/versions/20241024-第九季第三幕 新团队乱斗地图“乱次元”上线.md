# 第九季第三幕 新团队乱斗地图“乱次元”上线

> **日期**：2024-10-24 ｜ **类型**：大版本
> **公告时间**：2024-10-23 12:20:17

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在10月24日1:00~5:00进行停机版本更新，第九季第二幕竞技模式将于10月23日 22:00正式结束，停机更新结束后将进入第九季第三幕新赛季，竞技模式段位将进行重置。此外，第九季第二幕战斗通行证也将在停机更新开启时正式结束。
 
大家好，欢迎迈入第九季第三幕!
大家都看到&ldquo;日落之城&rdquo;有更新的消息了吧?现在已经在游戏里实装了。同一时间上线的，还有我们最新的团队乱斗地图&mdash;&mdash;&ldquo;乱次元&rdquo;。
本次更新内容还包括：地图轮换变更，夜露出其不意与部分英雄技能的互动效果调整，同样发生变化的还有盖可的技能&mdash;&mdash;也就是他的噬源兽小伙伴，以及更多内容!
 
本次v9.08版本更新内容如下：
英雄更新
盖可
盖可的技能在7.12版本中得到加强后，玩家对它们已经熟稔于心，使用技能再回收的核心玩法几乎没有短板。以下针对球体的改动会迫使盖可更早地回收它们，给对手更多反制他的机会，如果他过于鲁莽，就会受到惩罚。
丢丢和皮蛋的整体可靠性得到了提升，以减少这种恼人的情况：明明听到或看到它们瞄准了敌人、进行了减益，结果敌人却没有受到影响。以上改动并非直接对盖可实力的直接增强，而是旨在解决游戏表现上的不一致。
目前玩家射击反制丢丢的成功率处在较为健康的状态，但我们认为它控制战场空间和特定角度的时间有些太长了。此外，考虑到盖可经常使用皮蛋进行安装和拆除爆能器，以此获得终极技能点数，让鲨鲨的激活频率显得有些太高了。
我们希望这些改动不会大幅改变盖可在游戏中的定位，而是让他在长远角度上更加平衡。
● 球体
○ 在环境中的留存时间从20秒减少至15秒
○ 回收时间从1秒增加至1.5秒
● 炫晕光波
○ 投掷和成型后的激活时间从1.5秒减少至1秒。
○ 丢丢的瞄准算法已更新，变得更加可靠。
○ 丢丢的电浆闪光弹现在会对受影响玩家的小地图也造成致盲效果。
● 顽皮搭档
○ 锥形震荡区的范围从45度增加至65度。
○ 部署爆能器后，皮蛋在变成球体时会有独特的视觉效果。
● 无敌超鲨
○ 所需点数从7点增加至8点
 
夜露
英雄的各种技能对夜露的出其不意镜像没有效果，因此很容易区分哪个才是真正的夜露。我们会检查游戏中英雄的各项技能，确保它们与夜露的出其不意正确互动。
● 像盖可的炫晕光波和维斯的弧光玫瑰这样的致盲技能，现在会让夜露的出其不意镜像和英雄本体一样显示出致盲效果。
● 在致盲假夜露时，维斯会说出成功致盲的庆祝台词。
● 零的神经取析将显示夜露的出其不意镜像。
● 暮蝶的整蛊现在会让夜露的出其不意镜像显示出腐坏效果。
 
斯凯和捷风
● 捷风的逐风和斯凯的辟林之虎将不再会被亚海悬城的窗户停下。相反，它们会冲破窗户，继续向另一侧移动。
 
外观物品更新
● 我们更新了几个瞄准镜的视效，让它们更加简洁，减少视觉干扰。以下是获得更新的皮肤;归零者 冥驹、盖世英雄 冥驹、掠影 冥驹、哥特废墟 飞将。
 
地图更新

《无畏契约》团队乱斗最新地图&ldquo;乱次元&rdquo;现已推出
● 这是一张双主题的5v5团队乱斗地图，加入团队乱斗游戏模式队列，即可体验&ldquo;乱次元&rdquo;。

 
地图轮换
● 深海明珠和霓虹町回归竞技模式队列。
● 森寒冬港和莲华古城离开竞技模式队列。
● 改动后，竞技模式队列地图为：深海明珠，霓虹町，亚海悬城，隐世修所，源工重镇，日落之城，幽邃地窟
 
日落之城
我们正在更新日落之城的B区布局，以解决一些防守和下包后的战斗问题，并为该区域提供更多战术空间。B区大道的主箱会在下包后带来巨大压力，因此我们选择简化这里的掩体。你仍然可以在下包后据守B区大道，但现在对于防守方来说，重新夺回B区会更加容易。随着这些改动，零的一处绊线位置也被移除了。
