# v9.06版本

> **日期**：2024-09-26 ｜ **类型**：小版本
> **公告时间**：2024-09-25 21:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 9月26日 8:00 进行不停机版本更新，更新过程中大家可以在游戏内正常进行对局，若有偶现的匹配不可用请稍作等待即可恢复，为您带来的不便我们深表抱歉。
本次v9.06版本更新内容如下：
英雄更新
● 涉及墙体的英雄技能与亚海悬城玻璃窗的交互作用有所改变。
 ○ 不死鸟的火冒三丈和霓虹的高速通道，如果技能的初始施放中心点命中窗户，则窗户会被打破，技能本身的墙体并不会和窗户发生交互。
 ○ 海神的狂潮不会碰到墙体，所以也不会再打破玻璃窗。
 ○ 放置距离过近时，尚勃勒的贵宾限行、零的震慑绊线和奇乐的全面封锁将不再打破窗户。
● 炼狱的天基光束和维斯的铁棘禁园，我们分别为这两个技能的范围效果更新了蓄力/激活效果和蓄力音效表现。这些效果原先会直接置于英雄身上，现在改为稍微朝向范围效果的源头，让玩家知道该往哪个方向逃脱。
玩法系统更新
● 新手提示(仅对新账号默认开启)
 ○ 从完成教程到开始在战场上磨练枪法，我们希望刚加入的玩家可以在这一过程中掌握正确的信息，为胜利打下坚实的基础!因此，我们实装了一套&ldquo;新手提示&rdquo;系统。该系统将根据你在比赛中采取的行动，显示有用的游戏资讯&mdash;&mdash;其中包括基础玩法的关键信息、提高技术水平的潜在要点，以及高级策略的指导建议。
 ○ 这一新手提示系统是我们从零开始打造的，希望可以为玩家提供更多提升技术水平的机会，让大家快速掌握《无畏契约》的要领，具体方式如下：
 ■ 根据你在比赛中的表现和行为提供指导
 ■ 根据你学习《无畏契约》基础玩法的进度提供相应的指导(从初级到高级策略)
 ○ 提示可以在设置中打开或关闭。
 ○ 备注：除非在设置中自行开启，新手提示将不对现有玩家显示。
● 更新了投票系统，平局投票不再计入挂机玩家的票数。
地图更新
● 隐世修所
 ○ 推出了几项体验升级，帮助玩家在隐世修所的箱子上部署维斯的弧光玫瑰和零的震慑绊线。
● 微风岛屿
 ○ 修复了位于A区小房间的机械门即使开着，子弹也无法穿过的问题。
玩家行为更新
● 为了在《无畏契约》中创造更健康的通讯体验，我们调整了通讯行为不当的惩罚。屡次通讯行为不当的玩家将受到更严厉的惩处。
社交更新
● 我们更新了语音聊天系统。在意外断开连接后，玩家重新连接到语音聊天系统的稳定性将有所提升。
武器更新
● 我们将为游戏内的武器切换键添加武器皮肤名称。我们希望这一改动可以帮助大家在捡起或切换武器时更容易确定自己正在使用的皮肤。这项改动将反映在游戏内的HUD界面上。
错误修复
英雄
● 修复了钢锁在部署声感陷阱时被击败，装置会一直保持激活状态的问题。
● 修复了零的震慑绊线不会受到某些技能伤害的问题。
● 修复了盖可的顽皮搭档在尝试追逐不可及目标时可能会陷入循环的问题。
● 修复了夜露的出其不意无法触发维斯的裁断的问题。
● 修复了铁臂无法通过维斯的裁断施放技能的问题。
● 修复了猎枭的寻敌箭会被维斯的裁断破坏的问题。
● 修复了盖可的无敌超鲨和雷兹的晚安焰火可以命中位于维斯的裁断另一侧的人的问题。
● 修复了维斯的弧光玫瑰可以被放置在无效物体上的问题。
● 修复了维斯的裁断瓦解时可以阻挡子弹和人的各种碰撞问题。
● 修复了角色的身体会在维斯的裁断内发生穿模的问题。
● 修复了维斯的剃刀藤蔓和裁断在提前取消时会出现视觉效果残留的问题。
外观物品
● 修复了夜刃诡镰的第三人称动画。玩家在装备这件近战武器时，它将不再高于英雄模型。
玩法系统
● 修复了击败队友时，战斗记录不会显示&ldquo;击败&rdquo;文本的问题。
已知问题
● 新手提示目前仅能在新手教程后的机器人训练比赛中开启显示，其余情况下无法开启
 
感谢您对《无畏契约》的支持和帮助!
