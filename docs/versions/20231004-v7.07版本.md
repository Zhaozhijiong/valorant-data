# v7.07版本

> **日期**：2023-10-04 ｜ **类型**：小版本
> **公告时间**：2023-10-03 14:02:54

## 更新内容

大家好!各位亲爱的玩家朋友，《无畏契约》预计将在10月4日 上午5:00进行不停机版本更新，更新过程中各位玩家可以在游戏内进行正常体验，更新过程中可能会出现短暂匹配异常或服务波动等情况，为各位玩家带来的不便我们深表抱歉。
 
本次v7.07版本更新内容如下：
竞技模式更新
● 移除了超凡以上段位组队限制，但最新的排位拖分治理机制依然严格生效，点击此处查看最新排位拖分处罚规则>>
 
地图更新
● 我们升级了游戏地图轮转策略，减少连续多场比赛进入相同地图的概率。
● 我们调整了隐士修所地图中，位于中区门/车库的门板，更新了其摧毁特效，使其在破碎掉落时更容易被玩家关注到。
 
游戏性能更新
● 我们为英特尔的独立显卡启用了多线程渲染，同时降低了需要的 CPU 内核数，为部分用户的游戏对局体验提升了流畅度。
 
错误修复
英雄
● 零
 ○ 修复了零在施放神经取析(X)后阵亡，会导致技能无法完成的问题。
 ○ 修复了通过零的监控镜头(E)看到闪光而被致盲时，即使回合结束，也无法解除致盲效果的问题。
● 盖可
 ○ 修复了炫晕光波(E)处于蝰腹(X)范围内时，敌人侦察范围无法正确缩小的问题。
 
商城更新
10月5日 ，盖亚的复仇//2.0 套装将上架游戏商城!
套装由盖亚的复仇//2.0 幻影 、盖亚的复仇//2.0 战神、盖亚的复仇//2.0 雄鹿、盖亚的复仇//2.0 短炮、盖亚之愠、盖亚的复仇//2.0 喷漆、盖亚的复仇//2.0 卡面、盖亚的复仇//2.0 挂饰 等八件道具组成。
