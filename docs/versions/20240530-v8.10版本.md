# v8.10版本

> **日期**：2024-05-30 ｜ **类型**：小版本
> **公告时间**：2024-05-29 21:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 5月30日1:00~5:00 进行停机版本更新，竞技模式将于 5月29日 23:00 暂时关闭，停机更新结束后将重新开放，请合理安排您的游戏时间。
本次v8.10版本更新内容如下：
错误修复
英雄
● 修复了玩家退出零的战术监控(E)时间后立即射击、会跳过武器切换动画、且无法造成伤害的问题。从现在开始，武器切换动画将完整播放。
● 修复了暮蝶虹吸(C)的计时器可能重启，导致暮蝶激活此技能的可用时间多于预期的问题。
 
此外，《无畏契约》原计划在本次版本中对玩家进程系统进行一次更新，为新注册游戏的玩家带来更多游戏引导。但由于该系统在国服版本的部署是存在稳定性问题，目前拳头游戏的开发团队仍在全力解决中，因此我们预计将在下个版本中再进行该内容的更新。
 
感谢您对《无畏契约》的支持和帮助!
