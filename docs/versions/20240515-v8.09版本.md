# v8.09版本

> **日期**：2024-05-15 ｜ **类型**：小版本
> **公告时间**：2024-05-14 21:00:00

## 更新内容

各位亲爱的玩家朋友，《无畏契约》预计将在 5月15日5:00 进行不停机版本更新，更新过程中大家可以在游戏内正常进行对局，若有偶现的匹配不可用请稍作等待即可恢复，为您带来的不便我们深表抱歉。
本次v8.09版本更新内容如下：
英雄更新
炼狱
●我们对炼狱的空投烟幕(E)做了一些小小的更新，确保烟雾在放置后能够完全覆盖界面指示的区域。这样一来，只要瞄准界面的外缘覆盖到特定位置，产生的烟雾也会完全覆盖该区域。同时我们也略微增加了炼狱烟雾的半径，使其与幽影等同类英雄的烟雾大小保持一致。
 ○空投烟幕(E)
 ■半径从410增加至415
 ■更新了UI的瞄准尺寸，以确保其外缘正确反映烟雾的大小
错误修复
玩法系统
●修复了一个导致玩家丢失准星档案的问题。
 ○虽然我们无法恢复已经丢失的准星档案，但非常感谢大家提供的信息。多亏你们，我们才能迅速找到解决办法。我们之后也会持续跟踪，密切关注相关情况。
 ○如果你新创建的准星档案依旧存在丢失的问题，请联系我们的客服，告知具体情况。
●修复了战斗记录中&ldquo;击败者&rdquo;信息不正确的问题。
●修复了在设置中关闭弹道显示后，玩家朝着地图外的方向开枪，弹道依旧可见的问题。
●修复了游戏结束后，客户端陷入无响应，需要重启客户端才能继续的问题。
●修复了靶场中计时器失效的问题。
 
感谢您对《无畏契约》的支持和帮助!
